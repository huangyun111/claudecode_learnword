# 2026-11-07 · 主动感知与 Next-Best-View：相机下一步该往哪里看

> 阶段 L · 主动感知、具身几何与闭环采集（L1）｜标签：active perception, next-best-view, Bayesian experimental design, information gain, Fisher information, visibility, active reconstruction, coverage, uncertainty calibration
> 主线：被动重建回答“给定这些图像，能恢复什么”；主动感知再多问一步——“如果还能拍一张，应该去哪里拍”。关键不是追逐最大的 uncertainty，而是比较每个候选观测对目标参数能减少多少不确定性，再把 visibility、运动成本、安全与模型失配一起放进闭环。

---

## 开篇：模型说“背面不确定”，相机就该直接绕到背面吗

你已经绕着一个雕塑拍了六张照片。重建模型给出一张 uncertainty map：正面很确定，背面很不确定。

最直觉的策略是：去最不确定的地方。

但“那里不确定”不等于“下一张图能解决那里”：

- 背面也许被底座遮挡，候选相机根本看不到；
- 新视角可能与旧视角几乎共线，只重复同一种几何约束；
- 走过去需要很长路径，途中还可能碰撞；
- uncertainty 可能来自模型没学会，而不是数据真的不足；
- 如果最终目标是完整 mesh，降低颜色不确定性未必改善 surface completeness。

因此 **Next-Best-View（NBV）** 不是“找最大红色区域”，而是一个顺序实验设计问题：

~~~text
当前观测 D_t
  -> 当前 belief / map
  -> 生成可达候选视角 a
  -> 预测每个 a 会看到什么、能减少什么不确定性
  -> 扣除路径、时间、风险与失败成本
  -> 执行一个动作，获得真实观测 y
  -> 更新 belief，再规划下一步
~~~

这正是从 passive reconstruction 走向 active perception 的分界线。

## 第一层直觉：好视角不是“看见更多”，而是排除更多仍可能成立的世界

假设桌上有一根细杆。只从正面看，它可能很短，也可能沿视线方向延伸得很长。你再沿几乎相同方向拍一张高清图，像素更多了，但“深度究竟多长”的多解没有真正消失。

如果第二张图从侧面拍，原本藏在视线方向里的长度被展开。新图的价值不只在于新增像素，而在于它切断了旧观测的 **null direction**。

所以主动感知真正关心的是：

> 候选观测是否提供了与现有观测互补的约束。

“覆盖新区域”是一种互补；“从不同基线观察同一表面”也是；“改变光照或偏振角以区分材质与法向”仍然是。

## 第二层：把当前知识写成一个概率分布

先用最小线性高斯模型理解信息增益。

设未知场景参数为列向量

$$
\boldsymbol\theta\in\mathbb R^d,
$$

其中可以放入点坐标、局部 surface 参数、相机 pose，或某个低维 toy scene 的几何量。采下一张图之前，我们对它的 belief 写成 Gaussian：

$$
p(\boldsymbol\theta\mid D_t)
=\mathcal N(\boldsymbol\mu_t,\mathbf\Sigma_t).
$$

- $D_t$：截至时刻 $t$ 已有的数据；
- $\boldsymbol\mu_t$：当前最可能的参数；
- $\mathbf\Sigma_t$：posterior covariance；沿某个方向方差越大，表示那个参数组合越不确定。

候选视角或动作记为 $a$。它产生观测

$$
\mathbf y_a=\mathbf H_a\boldsymbol\theta+\boldsymbol\varepsilon_a,
\qquad
\boldsymbol\varepsilon_a\sim\mathcal N(\mathbf0,\mathbf R_a).
$$

- $\mathbf H_a$：这个视角怎样“读取”场景参数；它包含投影方向与局部 sensitivity；
- $\mathbf R_a$：观测噪声 covariance；模糊、远距离、弱纹理或标定误差会让它变大。

这里最重要的不是 linear 假设本身，而是：**动作 $a$ 会改变 measurement Jacobian，也就改变哪些参数方向可被观察。**

## 第三层：从 Bayes 更新推出 posterior covariance

先写 prior 的负对数中与 $\boldsymbol\theta$ 有关的部分：

$$
-\log p(\boldsymbol\theta\mid D_t)
=\frac12(\boldsymbol\theta-\boldsymbol\mu_t)^\top
\mathbf\Sigma_t^{-1}
(\boldsymbol\theta-\boldsymbol\mu_t)+C_1.
$$

给定候选观测 $\mathbf y_a$，likelihood 的负对数是

$$
-\log p(\mathbf y_a\mid\boldsymbol\theta,a)
=\frac12(\mathbf y_a-\mathbf H_a\boldsymbol\theta)^\top
\mathbf R_a^{-1}
(\mathbf y_a-\mathbf H_a\boldsymbol\theta)+C_2.
$$

Bayes rule 让 posterior 正比于 prior 乘 likelihood，所以两段二次型相加。只收集关于 $\boldsymbol\theta$ 的二次项：

$$
\frac12\boldsymbol\theta^\top
\left(
\mathbf\Sigma_t^{-1}
+\mathbf H_a^\top\mathbf R_a^{-1}\mathbf H_a
\right)
\boldsymbol\theta.
$$

Gaussian 二次型前面的矩阵就是 precision，也就是 covariance 的逆。因此

$$
\boxed{
\mathbf\Sigma_{t+1}^{-1}
=\mathbf\Sigma_t^{-1}
+\mathbf H_a^\top\mathbf R_a^{-1}\mathbf H_a
}
$$

或等价地

$$
\boxed{
\mathbf\Sigma_{t+1}
=\left(
\mathbf\Sigma_t^{-1}
+\mathbf H_a^\top\mathbf R_a^{-1}\mathbf H_a
\right)^{-1}.
}
$$

第二项

$$
\mathbf H_a^\top\mathbf R_a^{-1}\mathbf H_a
$$

就是该观测带来的 information。它同时表达三件事：

1. $mathbf H_a$ 对某个参数方向越敏感，信息越大；
2. 噪声 $mathbf R_a$ 越小，信息越可信；
3. 若它只重复已有方向，某些未约束方向仍不会消失。

## 第四层：为什么 Information Gain 会变成 log-determinant

$d$ 维 Gaussian 的 differential entropy 为

$$
h(\boldsymbol\theta)
=\frac12\log\left((2\pi e)^d\det\mathbf\Sigma\right).
$$

$\det\mathbf\Sigma$ 可以理解为 uncertainty ellipsoid 的“体积平方尺度”。候选动作 $a$ 带来的 entropy reduction 是

$$
\mathrm{IG}(a)
=h_t-h_{t+1}
=\frac12\log\frac{\det\mathbf\Sigma_t}
{\det\mathbf\Sigma_{t+1}}.
$$

代入 posterior precision，并使用 determinant identity，可得

$$
\boxed{
\mathrm{IG}(a)
=\frac12\log\det\left(
\mathbf I+
\mathbf\Sigma_t\mathbf H_a^\top
\mathbf R_a^{-1}\mathbf H_a
\right).
}
$$

这一步告诉我们：NBV 不是只比较预测 variance，而是比较 **执行这个观测之后，整个目标参数空间会缩小多少**。

在非线性 neural field 中，常在当前参数附近做局部 linearization：

$$
f(\boldsymbol\theta,a)
\approx f(\hat{\boldsymbol\theta},a)
+\mathbf J_a(\boldsymbol\theta-\hat{\boldsymbol\theta}),
$$

再用 Jacobian $mathbf J_a$ 构造局部 Fisher information。注意：这只是当前模型附近的局部近似，不会自动发现模型族之外的错误。

## 第五层：为什么“重复看同一方向”会收益递减

假设未知点只有二维坐标

$$
\boldsymbol\theta=[x,y]^\top,
$$

初始 covariance 为 $\mathbf I$。每次观测只能测量方向 $\mathbf n=[\cos\alpha,\sin\alpha]$ 上的投影：

$$
y_\alpha=\mathbf n^\top\boldsymbol\theta+\varepsilon.
$$

从 $0^\circ$ 方向观测后，$x$ 被约束，$y$ 仍模糊。再从 $0^\circ$ 看，只会继续压缩 $x$；从 $90^\circ$ 看才会补上 $y$。这就是“更多帧”与“更多独立约束”的区别。

下面的纯 Python 代码用 $2\times2$ covariance 演示这个选择：

```python
from math import cos, sin, pi, log

def inv2(m):
    a, b = m[0]
    c, d = m[1]
    det = a * d - b * c
    return [[d / det, -b / det], [-c / det, a / det]]

def det2(m):
    return m[0][0] * m[1][1] - m[0][1] * m[1][0]

def posterior_cov(cov, angle_deg, noise_var=0.25):
    t = angle_deg * pi / 180.0
    h = [cos(t), sin(t)]
    precision = inv2(cov)
    for i in range(2):
        for j in range(2):
            precision[i][j] += h[i] * h[j] / noise_var
    return inv2(precision)

def information_gain(cov, angle_deg):
    post = posterior_cov(cov, angle_deg)
    return 0.5 * log(det2(cov) / det2(post), 2), post

# 已经从 0 度方向观测过一次
cov = posterior_cov([[1.0, 0.0], [0.0, 1.0]], 0)

for angle in [0, 30, 60, 90]:
    gain, post = information_gain(cov, angle)
    print(f"angle={angle:>2} deg, gain={gain:.4f} bits, det={det2(post):.6f}")
```

预期结果是 $90^\circ$ 的 gain 最大：它不是“画面最不一样”这么简单，而是补足了当前最弱的参数方向。

## 第六层：从 Information Gain 走到真正可执行的 utility

真实机器人或采集系统不能只最大化 IG。一个更完整的 score 可以写成

$$
U(a)=
p_{\mathrm{vis}}(a)\,\mathrm{IG}_{\mathrm{target}}(a)
+\beta\,\Delta\mathrm{Coverage}(a)
-\lambda\,C_{\mathrm{motion}}(a)
-\gamma\,C_{\mathrm{risk}}(a).
$$

- $p_{\mathrm{vis}}(a)$：目标区域在候选视角真实可见的概率；
- $\mathrm{IG}_{\mathrm{target}}$：针对最终任务参数的信息增益，而非任意 feature variance；
- $\Delta\mathrm{Coverage}$：新增可见表面或空间 frontier；
- $C_{\mathrm{motion}}$：距离、能耗、时间与转动成本；
- $C_{\mathrm{risk}}$：碰撞、视野丢失、动态物体与硬件约束风险；
- $\beta,\lambda,\gamma$：由任务预算决定的权重。

这解释了两个常见现象：

1. 最不确定的区域如果不可见，预期收益接近零；
2. 远处视角即使信息略高，也可能因路径和风险不值得执行。

规划通常还要用 **receding horizon**：只执行当前计划的第一步，拿到真实图像后重新估计，而不是把一条长轨迹一次性锁死。因为每次新观测都会改变 map、visibility 与下一步价值。

## 第七层：Uncertainty 为什么可能把主动系统带偏

### 1. Epistemic uncertainty 与 reconstruction error 不是同一个量

ensemble disagreement、weight perturbation、density entropy 或 radiance variance 都是 proxy。它们必须在 held-out 数据上验证：高 score 是否真的对应高几何误差，采样后是否真的带来更大改进。

### 2. 模型失配可能产生“自信地错”

如果表示无法表达透明、镜面、细结构或动态物体，posterior 可能很窄，但答案仍错。局部 Fisher information 只告诉你当前模型内部哪些方向可区分，不能证明模型族包含真实世界。

### 3. 主动策略会改变自己的数据分布

策略偏爱它认为有价值的视角，训练数据于是越来越像自己的偏好。错误 uncertainty 会产生反馈回路：错误地忽略某一区域，就永远收不到纠正它的数据。

### 4. Appearance gain 不能代替 geometry gain

某个视角可能显著改善 novel-view PSNR，却没有增加 surface completeness；也可能补全轮廓，但纹理指标几乎不变。utility 必须对齐 claim。

## 第八层：怎样证明 NBV 策略真的更好

冻结同一初始观测、相机动力学、最大帧数、路径长度或时间预算，然后比较：

- random policy；
- uniform / hemisphere coverage；
- frontier-based policy；
- uncertainty-only；
- uncertainty + visibility；
- 完整 information / cost / safety policy；
- oracle（只作为上界，不是可部署 baseline）。

结果至少分五层报告：

| 层 | 指标 | 它证明什么 |
|---|---|---|
| 采集 | path length、time、energy、collision / failure rate | 动作是否可执行 |
| 覆盖 | observed surface ratio、frontier reduction | 是否看到了更多区域 |
| 图像 | held-out PSNR / SSIM / LPIPS | 新视角外观是否更好 |
| 几何 | fixed-alignment accuracy / completeness / F-score / normal error | surface 是否真的恢复更好 |
| 决策 | predicted gain vs realized gain、regret、area under quality-budget curve | acquisition score 是否可信 |

还要在 unseen scenes、thin structure、specular / textureless surfaces、occlusion、pose noise 与 dynamic distractor 上报告 subgroup 和 worst-group。只在同一训练环境里展示一条漂亮轨迹，不能证明 NBV policy 会泛化。

## 与 CVPR / 偏振重建工作的连接

主动感知对偏振和多模态重建尤其有价值，因为“动作”不只可以是移动相机：

- 选择下一相机 viewpoint，改变 triangulation baseline；
- 旋转 analyzer，改变 Stokes measurement matrix；
- 改变 illumination direction，切断 albedo–normal ambiguity；
- 选择 RGB / depth / polarization 哪个 sensor 下一次采样；
- 决定把有限标注或 GT 预算放到哪个 scene / region。

但实验必须冻结 acquisition budget，并把 candidate 与 control 的传感器、曝光、路径、安全限制和终止规则匹配。若 candidate 多拍了更多帧、走了更长路径或用了额外 GT，就不能把提升只归因于“更聪明的 view selection”。

## 面试角度

### Q1：Next-Best-View 和 active learning 有什么共同点？

都在当前 belief 下选择下一条最有价值的数据。区别在于 NBV 的 action 往往受三维 visibility、相机动力学、碰撞和路径成本约束；active learning 常选择待标注样本，动作空间与成本结构不同。

### Q2：为什么不能直接选 predictive variance 最大的视角？

因为 variance 可能对应不可见区域、与目标 claim 无关的 appearance、重复约束或失配模型；还没有扣除运动成本和风险。应比较 action-conditioned expected utility，并校准 predicted gain 与 realized gain。

### Q3：Fisher information 大就说明真实几何一定更好吗？

不说明。它依赖局部线性化、噪声模型和当前 parameterization，只衡量模型内部的局部可辨识性。还需要独立几何 GT、固定 alignment、held-out scenes 和 failure subgroup 验证。

## 一句话总结

Next-Best-View 不是追着最大 uncertainty 跑，而是在当前 belief 下比较每个可执行观测能为目标参数增加多少独立信息，再用 visibility、coverage、路径、风险与模型失配把“理论上有信息”收缩成“现实中值得拍”；只有在冻结预算下验证 predicted gain、coverage、独立几何端点和失败率，主动采集才真正优于多拍几张。
