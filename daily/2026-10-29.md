# 2026-10-29 · 把光从物体上“剥下来”：Intrinsic Decomposition 为什么不能只靠重建原图

> 阶段 J · 第 3 篇 ｜ 标签：intrinsic decomposition, inverse rendering, albedo, normal, roughness, environment lighting, BRDF, light baking, relighting, identifiability
> 主线：一张照片的颜色不是材质本身，而是材质、几何、光照、可见性和相机共同作用的结果。只把训练图像重建好，完全可能把阴影烤进 albedo、把高光塞进 lighting、把错误 normal 藏进 roughness；真正的解耦证据来自未见光照、材质编辑和受控物理测量。

## 开篇：一块“深色木板”，可能只是背着光

你拍到一块木板，左半边浅、右半边深。至少有三种解释：

1. 右边真的涂了深色颜料；
2. 右边材质相同，只是被遮挡或背离光源；
3. 右边更粗糙，高光更宽、更弱，于是看起来更暗。

三种场景都能产生相近像素。若网络只需复现这张照片，它甚至不必作出选择：直接记住“这个三维位置就是这个颜色”即可。

但一旦换灯，区别立刻暴露。真正的深色纹理应该跟着物体走；旧阴影不该继续粘在表面；高光应随视线和光源移动。于是今天的核心不是“怎样输出几张漂亮的 intrinsic maps”，而是：

> 怎样让分解出的 geometry、material 与 lighting 在新的物理条件下仍产生正确结果？

## 1. 从 rendering equation 看：一个像素里混了哪些变量

表面点 $\mathbf x$ 沿观察方向 $\boldsymbol\omega_o$ 离开的 radiance 可写成

$$
L_o(\mathbf x,\boldsymbol\omega_o)
=
\int_{\Omega^+}
f_r(\mathbf x,\boldsymbol\omega_i,\boldsymbol\omega_o)
L_i(\mathbf x,\boldsymbol\omega_i)
V(\mathbf x,\boldsymbol\omega_i)
(\mathbf n^\top\boldsymbol\omega_i)_+
\,d\boldsymbol\omega_i.
$$

逐项解释：

- $\Omega^+$：表面上方半球内所有入射方向；
- $L_i$：从方向 $\boldsymbol\omega_i$ 到达表面的入射光；
- $V\in\{0,1\}$：该方向是否被遮挡；
- $\mathbf n$：surface normal；
- $(a)_+=\max(a,0)$：背面的光不直接照亮正面；
- $f_r$：BRDF，描述光从入射方向反射到观察方向的比例；
- 积分：把所有方向的贡献相加。

相机还会施加曝光、白平衡、响应曲线和 tone mapping。也就是说，像素颜色不是 albedo 的直接读数，而是一个多变量 forward model 的输出。

Intrinsic decomposition 就是尝试逆向恢复其中相对稳定、可编辑的因素，例如：

$$
\theta=(\rho,\mathbf n,\alpha,F_0,L_{env},V),
$$

其中 $\rho$ 是 diffuse albedo，$\alpha$ 是 roughness，$F_0$ 是法向入射时的 Fresnel reflectance，$L_{env}$ 是 environment lighting。

## 2. 最简单的 intrinsic image：$I=R\odot S$

先忽略高光、间接光和相机非线性，把 RGB 图像写成

$$
\mathbf I(\mathbf p)
=
\mathbf R(\mathbf p)\odot \mathbf S(\mathbf p),
$$

其中：

- $\mathbf p$ 是像素位置；
- $\mathbf R$ 是 reflectance / albedo；
- $\mathbf S$ 是 shading；
- $\odot$ 表示逐通道相乘。

取对数后：

$$
\log\mathbf I=\log\mathbf R+\log\mathbf S.
$$

这看似把乘法变成了容易分离的加法，但仍只有一个观测、两个未知量。对任意正常数 $c$，令

$$
\mathbf R'=c\mathbf R,
\qquad
\mathbf S'=\frac{1}{c}\mathbf S,
$$

就有

$$
\mathbf R'\odot\mathbf S'
=
(c\mathbf R)\odot\left(\frac{1}{c}\mathbf S\right)
=
\mathbf R\odot\mathbf S
=
\mathbf I.
$$

这叫 scale ambiguity。更糟的是，若允许 $c$ 随空间变化，低频纹理也能在 reflectance 与 shading 之间搬家。于是“重建误差为零”并不意味着分解正确。

## 3. Lambertian 小模型：normal、albedo 与 light 仍能互相补偿

在单方向光 $\mathbf l$、Lambertian 材质和灰度观测下，像素可近似为

$$
I=\rho E(\mathbf n^\top\mathbf l)_+,
$$

其中 $E$ 是光强，$\rho$ 是 albedo。

即使 $\mathbf l$ 已知，单像素也只有一个标量方程，却要估计 $\rho$ 和二维自由度的单位法向 $\mathbf n$。若光也未知，$E$、$\mathbf l$、$\rho$、$\mathbf n$ 都可以补偿彼此。

看梯度会更直观。设预测值

$$
\hat I=\rho E\,\mathbf n^\top\mathbf l
$$

且暂时假设点在受光半球，平方误差为

$$
\mathcal L=\frac12(\hat I-I)^2.
$$

记 residual 为 $r=\hat I-I$，则

$$
\frac{\partial\mathcal L}{\partial\rho}
=rE\,\mathbf n^\top\mathbf l,
$$

$$
\frac{\partial\mathcal L}{\partial E}
=r\rho\,\mathbf n^\top\mathbf l,
$$

$$
\frac{\partial\mathcal L}{\partial\mathbf n}
=r\rho E\mathbf l.
$$

同一个 residual 会同时推动 albedo、light strength 和 normal。优化器不会自动知道“真实错误属于谁”；parameterization、regularizer、初始化和数据变化决定最后由哪个变量背锅。

## 4. Roughness 为什么也会和 lighting 串通

真实材质常写成 diffuse 与 specular 两部分：

$$
f_r=f_d+f_s.
$$

Lambertian diffuse 项常近似为

$$
f_d=\frac{\rho}{\pi}.
$$

Microfacet specular 的典型结构是

$$
f_s
=
\frac{D_\alpha(\mathbf h)F(\boldsymbol\omega_i,\mathbf h)G(\boldsymbol\omega_i,\boldsymbol\omega_o)}
{4(\mathbf n^\top\boldsymbol\omega_i)(\mathbf n^\top\boldsymbol\omega_o)},
$$

其中：

- $\mathbf h$ 是入射与观察方向的 half vector；
- $D_\alpha$ 描述 microfacet normal distribution；
- roughness $\alpha$ 控制分布宽度；
- $F$ 是 Fresnel term；
- $G$ 是 masking-shadowing term。

粗糙表面通常产生更宽、更弱的高光；光滑表面产生更尖、更强的反射。但“宽高光”也可能来自一个面积更大的光源，“尖高光”也可能来自 environment map 中很小的亮点。

因此 roughness 与 environment lighting 的高频结构可以互相补偿：

~~~text
更光滑的材质 + 更模糊的环境光
          约等于
更粗糙的材质 + 更尖锐的环境光
~~~

训练视图下二者可能都拟合得很好，换一张具有不同频率结构的环境光后，错误才显现。

## 5. 什么是 light baking：模型把“当时的光”记成了“物体的颜色”

如果模型直接学习位置和观察方向到颜色的映射

$$
\mathbf c=F_\theta(\mathbf x,\boldsymbol\omega_o),
$$

它可以高质量重建固定照明下的训练图像，却没有显式变量告诉 renderer 哪部分是 material、哪部分是 lighting。

于是可能发生：

- cast shadow 被写进 texture / feature；
- specular highlight 被当成局部颜色；
- ambient occlusion 被当成 albedo 变暗；
- view-dependent network 用方向分支掩盖 normal 错误；
- exposure difference 被 lighting code 或 per-image appearance embedding 吸收。

这就是 light baking。它不一定是 bug：若目标只是固定光照下的 novel-view synthesis，baked appearance 可能非常有效；但它不能支持“已经恢复了可重光照材质”的主张。

## 6. 哪些观测能切断哪些歧义

没有一种额外数据能一次解决全部 ambiguity。要把 observation design 与目标歧义对应起来：

| 额外观测或约束 | 主要切断的歧义 | 仍然保留的边界 |
|---|---|---|
| 同一表面多视图、固定光 | view-dependent appearance 与几何一致性 | albedo–lighting scale 仍可能存在 |
| 同一视角多光照 | material 与 lighting 的补偿 | geometry 错误仍可污染 BRDF |
| 已标定光源 / environment map | illumination uncertainty | material model mismatch 仍存在 |
| 独立 depth / normal | geometry–appearance shortcut | roughness、$F_0$、indirect light 仍耦合 |
| cross-polarization capture | 部分分离 diffuse / specular | mixed reflection 与 calibration 仍需处理 |
| gray card / radiometric calibration | 绝对颜色与光强尺度 | 空间可见性和间接光仍未知 |

关键不是“模态越多越好”，而是每个观测是否真的改变了 Jacobian 的独立方向。若新增通道只是同一像素的确定性变换，它不会凭空增加物理可辨识性。

## 7. 最小可运行例子：训练图完全相同，换灯后立刻分出真假

下面用纯 Python 演示两类失败：全局 scale ambiguity，以及把训练光照烤进 texture。

```python
from math import sqrt

albedo_true = [0.20, 0.50, 0.80]
shading_train = [0.50, 1.00, 0.25]
shading_novel = [1.00, 0.40, 0.80]

def mul(a, b):
    return [x * y for x, y in zip(a, b)]

def rmse(a, b):
    return sqrt(sum((x - y) ** 2 for x, y in zip(a, b)) / len(a))

image_train = mul(albedo_true, shading_train)

# Ambiguous candidate: albedo * 2, training shading / 2.
albedo_scaled = [2.0 * x for x in albedo_true]
shading_scaled_train = [0.5 * x for x in shading_train]
reconstruction_scaled = mul(albedo_scaled, shading_scaled_train)

assert rmse(image_train, reconstruction_scaled) < 1e-12

# Under calibrated novel lighting, the wrong scale can no longer hide.
relit_true = mul(albedo_true, shading_novel)
relit_scaled = mul(albedo_scaled, shading_novel)

# Baked model treats the training image itself as a fixed surface color.
relit_baked = image_train

print("training reconstruction RMSE:", rmse(image_train, reconstruction_scaled))
print("scaled-decomposition relight RMSE:", round(rmse(relit_true, relit_scaled), 6))
print("baked-texture relight RMSE:", round(rmse(relit_true, relit_baked), 6))
```

预期输出：

```text
training reconstruction RMSE: 0.0
scaled-decomposition relight RMSE: 0.40398
baked-texture relight RMSE: 0.312836
```

训练重建把两种错误都放过了；已标定 novel lighting 则把 scale 与 baking 暴露出来。这就是 intervention 比同分布 reconstruction 更有辨别力的原因。

## 8. Relighting evidence 应该怎样分层

### 第 1 层：同光照 novel-view reconstruction

检查 geometry、visibility 与 appearance 能否从新视角合成。它不能证明材质—光照分解，因为 baked radiance 也能通过。

### 第 2 层：intrinsic map plausibility

展示 albedo、normal、roughness、environment map。它适合发现明显 artifact，但“看起来合理”不是定量真值。

### 第 3 层：有 GT 的 decomposition evaluation

在 synthetic 或受控 capture 上比较 albedo、normal、roughness、light direction / environment map。每张 map 要说明 gauge、scale、color-space 与 mask；不能用任意 per-scene alignment 抹掉本应恢复的绝对量。

### 第 4 层：held-out illumination relighting

训练中完全未见的光照作为 intervention，保持 camera、geometry、exposure 和 tone mapping protocol 冻结，比较 relit RGB、shadow placement、highlight motion 与 subgroup failures。

### 第 5 层：cross-combination 与物理端点

把已知 material A、geometry B、light C 交叉组合；或在真实采集中测量 BRDF / normal / calibrated HDR environment。只有这种组合能更强地排除网络记住联合外观。

一个严谨表格应至少把以下指标分开：

- same-light novel-view image quality；
- novel-light relighting quality；
- normal angular error；
- albedo chromaticity / scale-aware error；
- roughness / BRDF parameter error；
- worst-material、shadow、grazing-angle 与 specular subgroup；
- failure rate，而不只给平均 PSNR。

## 9. 与你的 CVPR / 偏振重建工作怎么接

偏振是很有价值的额外物理观测，但它也不是“自动解耦按钮”。AoLP、DoLP 与 analyzer intensity 主要增加 reflection geometry 和 normal / material 的约束；最终效果仍依赖 reflection model、calibration、mixed pixels 与 illumination。

若要证明 polarization 帮助材质—光照解耦，建议冻结：

1. 相同 geometry representation、camera、RGB views 与 initialization；
2. 相同 BRDF、environment-light parameterization 和 regularizer；
3. 只让 candidate 多使用 polarization observation；
4. 在 disjoint held-out lights 上比较 relighting；
5. 同时报告 normal、albedo、roughness 和 geometry，检查误差是否只是从一个变量搬到另一个变量；
6. 加入 polarization shuffle / calibration perturbation / irrelevant-channel negative control，验证收益来自正确物理对应。

最危险的结果是：polarization loss 降了、训练图更像了，但 roughness 或 environment map 吸收了错误，held-out relighting 没改善。那只能说明优化使用了信号，不能说明物理分解更正确。

## 10. 面试角度：六个高频追问

### Q1：Intrinsic decomposition 为什么 ill-posed？

因为像素是多个未知因素的乘积或积分，一个观测可由多组 albedo、normal、roughness、visibility 与 lighting 产生；存在 scale、频率和 parameter-compensation ambiguity。

### Q2：为什么低 photometric loss 不能证明 albedo 正确？

错误 albedo 可由 shading、light intensity、exposure 或 view-dependent appearance 补偿，最终渲染仍一致。

### Q3：Roughness 与 environment lighting 为什么耦合？

roughness 决定 specular lobe 的宽度，environment map 决定入射光的频率结构；更尖的 lobe 与更模糊的光，可能近似更宽的 lobe 与更尖的光。

### Q4：什么是 light baking？

模型把训练时的阴影、高光或间接光存进 texture / feature / radiance，因而能复现旧光照，却不能在新光照下正确移动这些效应。

### Q5：怎样检测模型真的会 relighting？

使用训练中未见、最好经过标定的光照；冻结 exposure 与 renderer protocol；检查 highlight、shadow、color transport 和独立 intrinsic endpoints，而非只看同光照 novel view。

### Q6：多光照是否足够恢复真实 BRDF？

不一定。若 geometry、visibility、camera response、indirect illumination 或 BRDF family 错误，参数仍可能补偿。多光照增加约束，但不等于完整可辨识。

## 11. 一张“分解证据十问卡”

1. **Forward model**：用了 Lambertian、microfacet 还是自由 neural appearance？
2. **Factors**：哪些变量显式分解，哪些被塞进 residual network？
3. **Gauge**：albedo / lighting 的尺度与颜色由什么锚定？
4. **Geometry**：normal 来自独立 geometry，还是也由 image loss 自由调整？
5. **Visibility**：cast shadow、self-shadow 与 indirect light 怎样建模？
6. **Roughness**：能否与 environment map 高频互相补偿？
7. **Baking**：texture / feature 是否携带训练光照？
8. **Intervention**：有没有真正未见的 illumination 或 material edit？
9. **Endpoint**：是否有独立 normal、BRDF、HDR light 或 relit GT？
10. **Protocol**：camera、exposure、mask、alignment 和 selection split 是否冻结？

## 12. 可靠来源

- [Barron & Malik, Shape, Illumination, and Reflectance from Shading, CVPR 2012](https://openaccess.thecvf.com/content_cvpr_2012/html/Barron_Shape_Illumination_and_2012_CVPR_paper.html)：把单幅图像分解为 shape、reflectance 与 illumination，并展示必须依赖统计与物理 priors 的逆问题结构。
- [Mildenhall et al., NeRF, ECCV 2020](https://www.matthewtancik.com/nerf)：展示 position / direction 到 radiance 的神经场与 novel-view synthesis；高质量固定光照重建并不自动提供可编辑 intrinsic factors。
- [Zhang et al., Modeling Indirect Illumination for Inverse Rendering, CVPR 2022](https://openaccess.thecvf.com/content/CVPR2022/papers/Zhang_Modeling_Indirect_Illumination_for_Inverse_Rendering_CVPR_2022_paper.pdf)：联合估计 shape、SVBRDF、visibility 与 indirect illumination，并明确展示 normal、albedo、roughness、environment map 和 novel-light relighting。
- [Yang et al., Complementary Intrinsics from NeRFs and CNNs for Outdoor Scene Relighting, CVPR 2023](https://openaccess.thecvf.com/content/CVPR2023/html/Yang_Complementary_Intrinsics_From_Neural_Radiance_Fields_and_CNNs_for_Outdoor_CVPR_2023_paper.html)：讨论 outdoor intrinsic decomposition、cast shadows、sky appearance 与 relighting 的联合证据。
- [Kouros et al., Unveiling the Ambiguity in Neural Inverse Rendering, CVPRW 2024](https://openaccess.thecvf.com/content/CVPR2024W/NRI/papers/Kouros_Unveiling_the_Ambiguity_in_Neural_Inverse_Rendering_A_Parameter_Compensation_CVPRW_2024_paper.pdf)：用 parameter compensation 分析材质与光照的多解，说明错误 roughness / environment map 可在训练条件下互相补偿，却在 relighting 中暴露。

## 一句话总结

Intrinsic decomposition 不是把一张图机械拆成几张 map，而是要求 albedo、normal、roughness、visibility 与 lighting 在新的观察和照明条件下仍各司其职；同光照 reconstruction 只能证明联合外观可拟合，held-out illumination、cross-combination 与独立物理端点才开始证明材质—光照真的被解耦。
