## ⏮ 上篇回顾（30 秒）

Dreamer 类 latent world model 学习

$$
p_\phi(\mathbf m_{t+1},r_{t+1},c_{t+1}
\mid \mathbf m_t,\mathbf a_t),
$$

再让 actor / critic 在 latent imagination 中学习行为。它不必为每个候选动作渲染高清像素，因此 rollout 便宜；但 latent state 是否遗漏真实世界的重要细节，必须由真实闭环结果检验。

Sora / Genie 类路线提出另一种可能：既然大规模视频模型已经能生成物体、相机和场景的连贯变化，能不能直接把这种 visual generation 变成一个可进入、可操纵、可供 agent 试错的世界？

## 🎮 开篇：电影和游戏都在“生成下一秒”，差别到底在哪里

想象两个系统：

```text
系统 A：输入“机器人穿过雪地”，一次生成 20 秒视频。
系统 B：先显示雪地；你每按一次左、右、跳，它才生成下一小段画面。
```

两者都可能看起来逼真，但 B 多了一份严格契约：

1. 同一历史下，不同 action 应产生有区别的后果；
2. action 的语义要稳定，不能这次“左”移动角色、下次移动背景；
3. 已经离开视野的物体，再回头时应仍在合理位置；
4. agent 不能靠模拟器漏洞获得现实中不存在的奖励。

因此，**视频生成质量不是交互式世界模型能力的充分条件**。它提供了强大的视觉先验，但从“会续写画面”到“能回答我这样做会怎样”，中间还要跨过 action、state、counterfactual 和 evaluation 四道门。

[OpenAI 的 Sora 技术报告](https://openai.com/index/video-generation-models-as-world-simulators/)把视频和图像压到 latent space，再切成 spacetime patches，由 diffusion transformer 统一建模；报告也明确把“world simulator”作为有前景的方向，同时展示了基础物理交互仍会失败。这个“能力与边界同时存在”的表述很重要。

## 🪜 台阶 1：先把三类模型放进同一张条件概率地图

定义：

- $\mathbf x_t$：时刻 $t$ 的可见画面；
- $\mathbf a_t$：时刻 $t$ 后施加的 action；
- $\mathbf c$：文本、首帧、草图等全局 condition；
- $\mathbf z_t=E(\mathbf x_t)$：视频 autoencoder 编码出的 latent frame；
- $\mathbf m_t$：面向决策的紧凑 latent state。

### 1. 开环 text-to-video

Sora 类系统可以抽象为

$$
p_\theta(\mathbf x_{1:T}\mid \mathbf c).
$$

它一次描述整段轨迹在 prompt 条件下有多大概率。生成后，用户通常不能在每一步插入 action 改写未来。

### 2. 闭环 generative interactive environment

Genie 类系统更接近

$$
p_\theta(\mathbf x_{t+1}
\mid \mathbf x_{\le t},\mathbf a_{\le t},\mathbf c).
$$

每次收到 action 后才生成下一 observation，再把新 observation 加回历史。用户与生成器形成闭环。

### 3. 面向决策的 latent world model

Dreamer 类系统更接近

$$
p_\phi(\mathbf m_{t+1},r_{t+1},c_{t+1}
\mid \mathbf m_t,\mathbf a_t).
$$

它不要求每一步都渲染漂亮画面，而要求 latent transition 对 reward、termination 和 planning 足够有用。

三者不是互斥类别：可交互生成器也能在 latent space 中工作，Dreamer 也可以带 observation decoder。真正的差别是训练数据、条件接口、生成节奏与评价目标。

## 🪜 台阶 2：Sora 为什么把视频切成 spacetime patches

原始视频张量可写成

$$
\mathbf x\in\mathbb R^{T\times H\times W\times C},
$$

其中 $T$ 是帧数，$H,W$ 是高宽，$C$ 是颜色通道。直接在像素上做大模型训练，token 数与计算成本都太高。

先用 encoder 压缩：

$$
\mathbf z=E(\mathbf x)
\in\mathbb R^{T'\times H'\times W'\times D}.
$$

再把 $\mathbf z$ 沿时间和空间切成小块，每个小块展平并投影为一个 patch token：

$$
\mathbf p_i=W\,\mathrm{vec}(\mathbf z[\mathcal B_i])+\mathbf b.
$$

这里 $\mathcal B_i$ 表示第 $i$ 个时空块，$W,\mathbf b$ 是可学习映射。这样做有三个作用：

1. 不同分辨率、宽高比和时长可被表示成不同数量的同类 token；
2. Transformer 能让远距离时空 patch 交换信息；
3. 计算在压缩 latent 上完成，不必反复处理全部像素。

但 patch 是 representation，不是物理定律。模型从数据相关性中学到“杯子通常不会瞬移”，并不保证内部显式保存了一个不可违反的刚体状态。

## 🪜 台阶 3：把 diffusion 接到“历史 + action”上

考虑生成下一帧 latent $\mathbf z_{t+1}$。训练时先对它加第 $n$ 级噪声：

$$
\tilde{\mathbf z}_{t+1}^{(n)}
=
\sqrt{\bar\alpha_n}\,\mathbf z_{t+1}
+
\sqrt{1-\bar\alpha_n}\,\boldsymbol\epsilon,
\qquad
\boldsymbol\epsilon\sim\mathcal N(\mathbf 0,\mathbf I).
$$

其中 $\bar\alpha_n$ 控制保留多少真实 signal。Denoiser 同时读取：

- 带噪的下一帧 latent；
- diffusion timestep $n$；
- 历史 latent $\mathbf z_{\le t}$；
- 当前 action $\mathbf a_t$；
- 可选的 prompt $\mathbf c$。

训练目标为

$$
\mathcal L_{\text{next}}
=
\mathbb E
\left[
\left\|
\boldsymbol\epsilon-
\boldsymbol\epsilon_\theta
(\tilde{\mathbf z}_{t+1}^{(n)},n,
\mathbf z_{\le t},\mathbf a_t,\mathbf c)
\right\|_2^2
\right].
$$

推理时，从噪声开始多步去噪得到 $\hat{\mathbf z}_{t+1}$，decode 为 $\hat{\mathbf x}_{t+1}$，再等待下一 action：

```text
history + action_t
      ↓
sample next latent frame
      ↓
decode and display x_(t+1)
      ↓
append to history, receive action_(t+1)
```

[Genie 2 的官方说明](https://deepmind.google/blog/genie-2-a-large-scale-foundation-world-model/)明确采用 autoregressive latent diffusion：autoencoder 提取 latent frame，大型 transformer 用 causal mask 建模历史，并在推理时逐帧接收 action。它说明“diffusion”与“autoregressive”并不矛盾：时间外层逐帧 rollout，每一帧内部再用 diffusion 去噪。

## 🪜 台阶 4：action condition 不等于模型真的服从 action

即使把 $\mathbf a_t$ 喂给网络，网络仍可能忽略它。若训练视频中“向右走”远多于“向左走”，只根据场景惯性预测也能得到不错的 reconstruction loss。

action classifier-free guidance 的直觉是，训练时偶尔丢掉 action，分别学会：

$$
\boldsymbol\epsilon_{\text{cond}}
=
\boldsymbol\epsilon_\theta(\cdots,\mathbf a_t),
$$

$$
\boldsymbol\epsilon_{\text{uncond}}
=
\boldsymbol\epsilon_\theta(\cdots,\varnothing).
$$

推理时放大二者差值：

$$
\boldsymbol\epsilon_{\text{guided}}
=
\boldsymbol\epsilon_{\text{uncond}}
+s\left(
\boldsymbol\epsilon_{\text{cond}}
-\boldsymbol\epsilon_{\text{uncond}}
\right),
$$

其中 $s\ge 1$ 是 guidance scale。差值近似“这个 action 相对自然演化想把画面推向哪里”。

但 $s$ 不是越大越好。过强 guidance 可能牺牲画面多样性、运动自然度，甚至放大训练数据中的 action shortcut。真正的 action use 必须用 matched counterfactual 检验：固定同一历史与随机种子，只替换 action，看后果是否按正确语义改变。

## 🪜 台阶 5：没有 action label，Genie 1 怎样学出 latent action

互联网视频通常只有画面，没有键盘记录。Genie 1 引入 latent action model，从相邻帧推断一个离散 action code：

$$
q_\psi(\mathbf u_t\mid \mathbf x_t,\mathbf x_{t+1}),
$$

再训练 dynamics model：

$$
p_\theta(\mathbf x_{t+1}
\mid \mathbf x_{\le t},\mathbf u_{\le t}).
$$

[Genie 论文](https://arxiv.org/abs/2402.15391)把系统分成 spatiotemporal video tokenizer、autoregressive dynamics model 和 latent action model。它的关键价值是：不用人工标注每个视频里的按键，也能从视觉变化中发现可复用的控制维度。

但 inferred latent action 不自动等于真实 actuator command。某个 code 可能混合“角色向右”“相机右移”“背景向左流动”。要把它用于机器人或真实决策，还需 action grounding：用少量带标签交互、policy data 或真实控制接口把 latent code 对齐到可执行语义。

## 🪜 台阶 6：长时一致性为什么比单段漂亮视频难

闭环生成会把自己的输出重新喂给自己：

$$
\hat{\mathbf x}_{t+1}
\sim p_\theta(\cdot\mid \hat{\mathbf x}_{\le t},\mathbf a_{\le t}).
$$

若每一步有很小的 state error，下一步的条件已经不再来自真实数据分布。误差会沿 rollout 累积，形成 exposure bias。

更难的是 occlusion memory。角色离开房间后，门是否已经打开、桌上杯子是否被拿走，都不在当前像素里。模型需要某种持久状态：

```text
当前可见画面 ≠ 完整世界状态
完整历史 token ≠ 无限容量记忆
看起来相似 ≠ 物体身份与因果状态相同
```

[Genie 3 的官方介绍](https://deepmind.google/blog/genie-3-a-new-frontier-for-world-models/)报告了实时交互、分钟级一致性与 promptable world events；这些是明显进步，但仍应按公开演示和官方描述理解，不能直接外推为任意真实物理环境中的长期准确 simulator。

## 🪜 台阶 7：从“相关续写”到“反事实模拟”需要什么

Agent planning 真正需要比较：

$$
p(\text{future}\mid h_t,\mathrm{do}(\mathbf a_t=a))
$$

与

$$
p(\text{future}\mid h_t,\mathrm{do}(\mathbf a_t=a')).
$$

$\mathrm{do}(\cdot)$ 强调主动干预，而不是观察数据里 action 与 future 的相关性。若训练视频中“角色跳跃”总与“镜头上移”同时出现，模型可能把相机运动当成跳跃后果。

因此最少要做四类诊断：

1. **action shuffle**：打乱 action 后性能应显著下降；
2. **same-state different-action**：同一历史换动作，后果应可区分；
3. **action semantics consistency**：同一 action 在不同场景仍保持核心语义；
4. **multi-step intervention**：不是只在下一帧响应，长期状态也应遵守动作后果。

若只看 FVD、视觉偏好或单条 demo，无法证明 counterfactual correctness。

## 🪜 台阶 8：生成环境能不能用于 agent planning，要过五层证据

可以把证据从弱到强排成五层：

| 层级 | 问题 | 典型指标 / 对照 |
|---|---|---|
| 视觉质量 | 单帧与短视频是否自然 | human preference, perceptual metric |
| 时空一致性 | 身份、几何、遮挡状态能否保持 | revisit test, long-rollout drift |
| action controllability | action 是否按稳定语义改变结果 | action classifier, shuffle / swap control |
| planning usefulness | simulator 中选出的 action 是否提高任务回报 | held-out task return, matched planner |
| real-world validity | 模拟器收益能否迁移到真实环境 | sim-to-real gap, safety / failure rate |

前一层不能替代后一层。一个 visually stunning simulator 可能给出错误碰撞动力学；agent 会学会利用错误，而不是学会现实技能。这就是 generative model exploitation，和 Dreamer 中的 model exploitation 是同一类问题，只是错误现在被渲染得更逼真。

## 🧪 最小可运行代码：模型到底有没有使用 action

下面构造一个一维小世界。真实角色位置满足

$$
s_{t+1}=s_t+a_t,
\qquad a_t\in\{-1,+1\}.
$$

我们比较两个模型：

- action-aware：从训练数据拟合位移与 action 的关系；
- action-agnostic：完全忽略 action，只预测平均位移。

```python
import numpy as np

rng = np.random.default_rng(7)

# 训练数据：next_position - position = action + small noise
n = 200
action = rng.choice([-1.0, 1.0], size=n)
delta = action + rng.normal(0.0, 0.08, size=n)

# 最小二乘：delta ≈ beta * action
beta = np.dot(action, delta) / np.dot(action, action)
mean_delta = delta.mean()  # ignoring action

# matched counterfactual：同一批起点，分别执行 left / right
state = rng.uniform(-3.0, 3.0, size=100)
left_true, right_true = state - 1.0, state + 1.0

left_action_model = state + beta * (-1.0)
right_action_model = state + beta * (+1.0)

left_no_action = state + mean_delta
right_no_action = state + mean_delta

def mse(x, y):
    return np.mean((x - y) ** 2)

aware_mse = 0.5 * (
    mse(left_action_model, left_true)
    + mse(right_action_model, right_true)
)
agnostic_mse = 0.5 * (
    mse(left_no_action, left_true)
    + mse(right_no_action, right_true)
)

aware_effect = np.mean(right_action_model - left_action_model)
agnostic_effect = np.mean(right_no_action - left_no_action)

print(f"fitted beta: {beta:.3f}")
print(f"action-aware counterfactual MSE: {aware_mse:.4f}")
print(f"action-agnostic counterfactual MSE: {agnostic_mse:.4f}")
print(f"predicted right-minus-left effect: {aware_effect:.3f}")
print(f"ignoring-action effect: {agnostic_effect:.3f}")
```

你应看到 action-aware 模型的 right-minus-left effect 接近真实值 $2$，而忽略 action 的模型 effect 为 $0$。这比只算普通 next-frame error 更接近“模型是否理解控制”的问题。

把它迁移到视频模型，就是固定历史、appearance latent 与随机种子，只改变 action，然后检查角色位移、相机变化、碰撞、物体状态和长期轨迹是否一起合理改变。

## 🔬 与你的 CVPR / 偏振工作有什么连接

### 1. 强生成先验不能替代物理证据

视频模型可能生成很平滑的 DoLP / AoLP 或 normal 序列，但平滑只证明 learned visual prior 强。偏振物理仍要检查四角强度、Stokes 恢复、AoLP 周期、Fresnel 约束和跨视角几何是否成立。

### 2. “可控生成”应做 matched intervention

如果控制变量是偏振角、光源、相机位姿或 material parameter，应固定其他输入，只改变一个 control，再测输出的响应方向与幅值。prompt 看似生效，不等于模型学到正确物理机制。

### 3. 生成数据可用于训练，但必须隔离评价

Sora / Genie 类模型可以补充多样 appearance、运动和遮挡情境；但由同一生成器制造的 train / test 可能共享 artifact。最终结论仍需真实 held-out data，且要分开报告 synthetic pretraining、real fine-tuning 与 strict real test。

### 4. 世界模型式评估可以补充单帧指标

对时序偏振或多视图任务，不只算 frame-wise MAE，还可检查：

- 同一物体跨帧的 identity / geometry consistency；
- 相机动作后预测的 view change 是否符合标定几何；
- 回到旧视角时物体属性是否恢复；
- 用预测做 planning 或 active view selection 时，真实误差是否下降。

## 🎤 面试角度：四个高频追问

### Q1：Sora 为什么可以被称为 world simulator，又为什么不能直接等同于可靠 world model？

它从大规模视频中学到对象、运动、视角和一部分交互规律，能生成某些具有持久状态的过程，所以呈现 simulator-like capabilities；但训练主要优化视觉分布拟合，公开证据仍包含物理失败，而且缺少普遍、可校准的 action-conditioned counterfactual 与真实 planning 验证。

### Q2：autoregressive diffusion 是什么意思？

autoregressive 描述帧与帧之间的时间分解：逐帧根据历史生成；diffusion 描述每个新 latent frame 内部怎样从噪声迭代去噪。两者处在不同层级，可以同时使用。

### Q3：latent action 的优点和风险是什么？

优点是无需昂贵 action label，可从海量视频发现控制维度；风险是 latent code 可能把主体动作、相机运动和环境变化混在一起，必须进一步 grounding 才能对应真实 actuator。

### Q4：怎样证明模型没有忽略 action？

做同历史、同随机种子、不同 action 的 matched counterfactual；再加 action shuffle、action removal 和跨场景语义一致性测试。仅看生成画面好不好不够。

## 🧭 一张最终地图

```text
Text-to-video
    学：视觉轨迹分布
    强：多样性、画质、开放域先验
    缺：逐步干预接口

Generative interactive environment
    学：history + action → next observation
    强：可进入、可反事实采样、可构造训练环境
    缺：长期状态、因果正确性、真实迁移仍需验证

Latent world model for control
    学：state + action → next state / reward / continuation
    强：便宜 rollout、直接服务 planning
    缺：可能丢掉视觉细节并产生 model exploitation

可靠 agent system
    需要：三者优势 + 闭环真实验证 + 不确定性与安全边界
```

## 一句话总结

Sora 类模型说明大规模视频生成能涌现对象、运动和一部分世界交互先验；Genie 类模型进一步把 latent video generation 接到逐步 action 上，使用户或 agent 能进入生成环境；但从“画面会响应”到“世界模型可用于规划”，还必须证明 action 真被使用、状态能长期保持、反事实后果正确、模拟器策略能迁移到真实闭环——画质是入口，不是结论。
