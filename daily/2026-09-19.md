## ⏮ 上篇回顾（30 秒）

Action-conditioned prediction 学习

$$
p(\text{future}\mid \text{past},\text{actions}),
$$

使模型能比较“采取不同动作会发生什么”。若直接在像素空间 rollout，模型每一步都要预测高维纹理、阴影和背景；这些细节很贵，却未必都影响任务。

Latent world model 改问：

```text
我能否把历史压成一个足以预测 reward、termination 与可控动力学的状态，
然后在这个紧凑状态里想象许多未来？
```

这不是说像素不重要，而是把“理解当前观测”与“反复模拟未来”分工。

## 🎮 开篇：学开车时，你会在脑中逐像素渲染挡风玻璃吗

人在准备变道时，通常不会先精确想象下一秒每片树叶、每块反光和每个压缩噪声。更关键的是：邻车相对位置、速度、车道边界、可用空间，以及变道后碰撞风险会怎样变化。

对 agent 也是如此。假设一帧 RGB 图像有 $256\times256\times3=196{,}608$ 个数，而真正控制任务的状态可能只有几十或几百维。若每评估一串候选动作都完整生成高清未来，计算会大量花在与决策无关的视觉细节上。

Dreamer 类方法的核心分工是：

1. **真实阶段**：从环境收集 observation、action、reward；
2. **建模阶段**：把历史编码为 latent state，并学习 latent dynamics；
3. **想象阶段**：不访问真实环境，只在 learned latent model 中 rollout；
4. **行为阶段**：用 imagined rewards 和 values 更新 actor / critic；
5. **再交互**：把 actor 放回真实环境，收集新数据并纠正世界模型。

[Dreamer 原论文](https://arxiv.org/abs/1912.01603)将它概括为“从图像学习世界模型，再纯粹通过 latent imagination 学习长时行为”；[DreamerV3](https://arxiv.org/abs/2301.04104)则把这套范式扩展到 150 多个不同任务，并强化了跨 domain 的训练稳定性。

## 🪜 台阶 1：先把环境写成 POMDP，而不是假设一帧图就是完整状态

定义：

- $\mathbf o_t$：时刻 $t$ 的高维 observation，例如图像；
- $\mathbf a_t$：agent 执行的 action；
- $r_t$：环境给出的 scalar reward；
- $c_t\in\{0,1\}$：episode 是否继续，终止时为 $0$；
- $\mathbf s_t$：环境真实状态，通常不可直接观测；
- $\mathbf m_t$：模型维护的 latent model state。

环境可以写成

$$
\mathbf s_{t+1}\sim p(\mathbf s_{t+1}\mid \mathbf s_t,\mathbf a_t),
$$

$$
\mathbf o_t\sim p(\mathbf o_t\mid \mathbf s_t),
\qquad
r_t\sim p(r_t\mid \mathbf s_t).
$$

单帧 $\mathbf o_t$ 可能看不见速度、遮挡物或接触力，所以这是 Partially Observable Markov Decision Process（POMDP）。模型必须把历史

$$
(\mathbf o_{\le t},\mathbf a_{<t})
$$

压成一个 belief-like latent state $\mathbf m_t$。好的 $\mathbf m_t$ 不要求重现世界的一切，只要尽量保留未来 reward 与 transition 所需的信息。

## 🪜 台阶 2：为什么 RSSM 同时保留 deterministic state 与 stochastic state

Dreamer 延续 PlaNet 的 Recurrent State-Space Model（RSSM）思路。[PlaNet](https://arxiv.org/abs/1811.04551)指出，latent dynamics 同时使用 deterministic 与 stochastic transition，可以在像素控制任务中表达记忆与不确定未来。

记：

- $\mathbf h_t$：deterministic recurrent state，负责累积历史记忆；
- $\mathbf z_t$：stochastic latent state，负责表达当前不确定因素；
- $\mathbf m_t=(\mathbf h_t,\mathbf z_t)$：完整 model state。

先更新确定性记忆：

$$
\mathbf h_t
=f_\phi(\mathbf h_{t-1},\mathbf z_{t-1},\mathbf a_{t-1}),
$$

其中 $f_\phi$ 常由 GRU 一类 recurrent network 实现，$\phi$ 表示 world model 参数。

为什么不能只用 $\mathbf h_t$？若同一 state-action 下存在多种结果，纯确定性 transition 容易把它们平均掉。

为什么不能只用独立的 $\mathbf z_t$？当前 observation 不一定包含速度和被遮挡历史，必须有 recurrent memory 把过去带来。

因此二者分工为：

```text
h_t：我从历史中确定地记住了什么
z_t：在这些历史约束下，当前还可能处于哪一种状态
```

它们是工程上的有用参数化，不应被误读为严格对应人脑中的“记忆”和“随机想法”。

## 🪜 台阶 3：posterior 看到了 observation，prior 只能靠动力学猜

这是整篇最关键的区别。

真实数据阶段，模型已经看到当前 observation $\mathbf o_t$。先用 encoder 得到 feature

$$
\mathbf e_t=E_\phi(\mathbf o_t),
$$

再用 representation posterior 推断 stochastic state：

$$
q_\phi(\mathbf z_t\mid \mathbf h_t,\mathbf e_t).
$$

它叫 posterior，是因为它在“看到当前证据之后”更新了对 $\mathbf z_t$ 的判断。

但想象未来时，未来 observation 还不存在，不能偷看 $\mathbf o_{t+1}$。因此只能使用 dynamics prior：

$$
p_\phi(\mathbf z_t\mid \mathbf h_t).
$$

于是存在两条路径：

```text
真实过滤：上一状态 + action → h_t；再看 o_t → posterior z_t
未来想象：上一状态 + action → h_t；不看 o_t → prior z_t
```

若训练时一直依赖 posterior，而 prior 学不会预测 posterior，模型一离开真实 observation 就会立刻漂移。所以下一步必须把两者拉近。

## 🪜 台阶 4：从生成模型角度推 world-model loss

给定 latent state $\mathbf m_t$，world model 通常预测：

$$
p_\phi(\mathbf o_t\mid \mathbf m_t),
\qquad
p_\phi(r_t\mid \mathbf m_t),
\qquad
p_\phi(c_t\mid \mathbf m_t).
$$

分别叫 observation model、reward model 与 continuation model。最后一个模型告诉 agent imagined trajectory 在该状态后是否还应继续计入未来回报。

理想目标是最大化真实序列的 log likelihood：

$$
\log p_\phi(\mathbf o_{1:T},r_{1:T},c_{1:T}\mid \mathbf a_{1:T}).
$$

但这里要对所有可能 latent sequence $\mathbf z_{1:T}$ 积分，直接计算很难。于是用 posterior $q_\phi$ 近似不可解的真实 posterior，并最大化 Evidence Lower Bound（ELBO）。把负号移到 loss 中，每个时间步可以写成

$$
\begin{aligned}
\mathcal L_{\text{model},t}
=&-\mathbb E_{q_\phi}
\big[\log p_\phi(\mathbf o_t\mid\mathbf m_t)\big]\\
&-\mathbb E_{q_\phi}
\big[\log p_\phi(r_t\mid\mathbf m_t)\big]\\
&-\mathbb E_{q_\phi}
\big[\log p_\phi(c_t\mid\mathbf m_t)\big]\\
&+\beta\,
D_{\mathrm{KL}}\!\left(
q_\phi(\mathbf z_t\mid\mathbf h_t,\mathbf e_t)
\,\|\,
p_\phi(\mathbf z_t\mid\mathbf h_t)
\right).
\end{aligned}
$$

逐项解释：

1. observation loss 迫使 latent 保留能解释当前观测的信息；
2. reward loss 迫使 latent 保留任务结果相关的信息；
3. continuation loss 学习终止风险；
4. KL 项要求“不看当前图的 prior”靠历史预测出接近 posterior 的分布；
5. $\beta$ 控制预测约束与重建自由度之间的权衡。

为什么 KL 方向写成 $D_{\mathrm{KL}}(q\|p)$？训练样本来自看过 observation 的 $q$，所以在这些 posterior samples 上惩罚 prior 给出过低概率；直观上是让 prior 学着复现 posterior 已经推断出的状态。

若 KL 太弱，posterior 可以把每帧编码成互不连续的“暗号”，prior 无法 rollout；若 KL 太强，posterior 被迫忽略 observation，所有状态挤成相似分布，出现 posterior collapse。实际 Dreamer 版本会采用 KL balancing、free bits / free nats、normalization 等稳定技巧，但机制仍是这场拉扯。

## 🪜 台阶 5：为什么“latent”不等于普通 autoencoder 的压缩向量

普通 autoencoder 优化

$$
\mathbf o_t\rightarrow\mathbf z_t\rightarrow\hat{\mathbf o}_t,
$$

只要求单帧可重建。它可能花大量容量记录背景纹理，却不保证 action 后怎样转移，更不保证 reward 可预测。

world-model latent 同时受四类信号塑造：

```text
当前观测能否解释？
给定 action 后能否预测下一 latent？
reward / termination 能否预测？
多步 rollout 后是否仍对行为学习有用？
```

因此“压得更小”不是唯一目标。过度压缩可能丢掉一个视觉上很小、对控制却致命的红灯；过度追求 pixel reconstruction 又可能优先记住树叶抖动。真正需要的是 task-relevant sufficiency，而它必须通过 reward prediction、long-horizon control 与 OOD 测试验证。

## 🪜 台阶 6：从真实状态出发，在 prior 里展开 imagined trajectory

从 replay buffer 取一段真实序列，经 posterior 得到起点

$$
\mathbf m_t=(\mathbf h_t,\mathbf z_t).
$$

接下来不再读取真实 observation。Actor 根据当前 imagined state 采样动作：

$$
\mathbf a_\tau\sim\pi_\theta(\mathbf a_\tau\mid\mathbf m_\tau),
$$

world model 用 prior 推下一状态：

$$
\mathbf h_{\tau+1}
=f_\phi(\mathbf h_\tau,\mathbf z_\tau,\mathbf a_\tau),
$$

$$
\mathbf z_{\tau+1}
\sim p_\phi(\mathbf z_{\tau+1}\mid\mathbf h_{\tau+1}),
$$

并预测

$$
\hat r_{\tau+1}=R_\phi(\mathbf m_{\tau+1}),
\qquad
\hat c_{\tau+1}=C_\phi(\mathbf m_{\tau+1}).
$$

重复 $H$ 步，就得到 imagined trajectory：

$$
(\mathbf m_t,\mathbf a_t,\hat r_{t+1},\hat c_{t+1},\ldots,\mathbf m_{t+H}).
$$

这里没有 decoder 逐帧画图。Decoder 在训练 world model 时提供 observation learning signal；行为学习只需 latent state、reward 与 continuation，所以同一批真实经验可以便宜地生成大量 imagined transitions。

## 🪜 台阶 7：critic 怎样把有限想象接到更远未来——$\lambda$-return

若 imagined horizon 只有 $H=15$，仅把 15 步内 reward 相加会让 agent 变得短视。于是训练 value model

$$
V_\psi(\mathbf m_t)
\approx
\mathbb E\left[
\sum_{k=0}^{\infty}
\gamma^k r_{t+k+1}
\right],
$$

其中 $\gamma\in[0,1)$ 是 discount factor，$\psi$ 是 critic 参数。

从 imagined trajectory 末端开始：

$$
G_H^\lambda=V_\psi(\mathbf m_{t+H}).
$$

再向前递推：

$$
G_k^\lambda
=
\hat r_{t+k+1}
+\gamma\hat c_{t+k+1}
\left[
(1-\lambda)V_\psi(\mathbf m_{t+k+1})
+\lambda G_{k+1}^\lambda
\right].
$$

这里：

- $\lambda=0$：每一步主要 bootstrap 下一状态 value，方差低但 bias 可能大；
- $\lambda=1$：尽量累加完整 imagined rewards，bias 小一些但更受 model error 与采样波动影响；
- 中间值：混合不同长度的 return，平衡 bias 与 variance。

critic 最小化

$$
\mathcal L_V
=\sum_{k=0}^{H-1}
\left(
V_\psi(\mathbf m_{t+k})
-\operatorname{sg}(G_k^\lambda)
\right)^2,
$$

其中 $\operatorname{sg}$ 表示 stop-gradient：更新 critic 时，把 target 当常数，避免目标和预测一起移动。

## 🪜 台阶 8：actor 学的不是复述数据，而是在 imagined dynamics 中提高 return

actor 目标是最大化 imagined $\lambda$-return：

$$
J(\theta)
=\mathbb E_{\pi_\theta,p_\phi}
\left[
\sum_{k=0}^{H-1}G_k^\lambda
\right].
$$

等价地最小化

$$
\mathcal L_\pi=-J(\theta).
$$

若 action 与 dynamics 可微，梯度可以沿

```text
actor action → latent transition → predicted reward/value
```

反向传播到 actor。离散 action 则可用 stochastic policy gradient 等估计。

这和上一篇的 MPC 不同：

| 方法 | 决策时做什么 | 主要代价 |
|---|---|---|
| PlaNet / MPC | 每个真实时间步在线搜索候选动作序列 | 推理时反复 planning |
| Dreamer | 训练时在 imagination 中学出 parametric actor | 训练 actor/critic，执行时一次前向 |

两者都用 learned world model，但“在线搜动作”与“离线把好行为蒸进 policy”不能混称。

## 🔁 台阶 9：完整闭环——模型、actor、critic 谁用哪一份数据

把流程串起来：

```text
真实环境交互
  ↓  (o_t, a_t, r_t, c_t)
Replay Buffer
  ↓
posterior 过滤真实序列，训练 world model
  ↓
从真实 posterior state 出发，用 prior 想象未来
  ↓
imagined rewards + continuation + values
  ↓
更新 actor 与 critic
  ↓
actor 回真实环境收集新经验
  └──────────────────────────────↺
```

三组目标不能混在一起：

- world model 用真实 replay 约束；
- actor / critic 主要用 imagined trajectories 学习；
- 最终能力必须回真实环境以 task return、success 与 safety 验证。

“纯 latent imagination 学行为”不等于 world model 从未看过真实数据，更不等于 agent 可以永久脱离环境自我提升。

## 🧪 最小可运行代码：把 16 维 observation 压到 2 维，再在 latent 中挑动作

下面构造一个二维真实状态 $[x,v]$，但 observation 是 16 维冗余传感器读数。我们用 PCA 得到 2 维 latent，拟合 action-conditioned latent dynamics 和 reward model，再完全在 latent 中评估动作序列。

这不是完整 Dreamer：它用枚举代替 actor-critic，用线性模型代替 RSSM；它隔离的是同一核心——**真实数据学习 compact dynamics，决策阶段不必重建高维 observation 就能想象动作后果。**

```python
import itertools
import numpy as np

rng = np.random.default_rng(7)
obs_dim = 16
sensor = rng.normal(size=(obs_dim, 2))
target = 1.0

def true_step(state, action):
    x, v = state
    next_state = np.array([x + v, 0.8 * v + 0.5 * action])
    reward = -(next_state[0] - target) ** 2 - 0.05 * action ** 2
    return next_state, reward

def observe(state):
    return sensor @ state + 0.01 * rng.normal(size=obs_dim)

# 1) 收集随机策略的真实经验
states, actions, next_states, rewards = [], [], [], []
state = np.array([0.0, 0.0])
for _ in range(4000):
    if rng.random() < 0.03:
        state = rng.uniform([-2.0, -0.8], [2.0, 0.8])
    action = float(rng.choice([-1.0, 0.0, 1.0]))
    next_state, reward = true_step(state, action)
    states.append(observe(state))
    actions.append(action)
    next_states.append(observe(next_state))
    rewards.append(reward)
    state = next_state

obs = np.asarray(states)
obs_next = np.asarray(next_states)
actions = np.asarray(actions)
rewards = np.asarray(rewards)

# 2) PCA encoder：16D observation -> 2D latent
mean = obs.mean(axis=0)
_, _, vt = np.linalg.svd(obs - mean, full_matrices=False)
encoder = vt[:2].T

def encode(x):
    return (x - mean) @ encoder

z = encode(obs)
z_next = encode(obs_next)

# 3) 学 latent transition: z_{t+1} = B [z_t, a_t, 1]
dyn_features = np.column_stack([z, actions, np.ones(len(z))])
B, *_ = np.linalg.lstsq(dyn_features, z_next, rcond=None)

def latent_step(latent, action):
    return np.array([latent[0], latent[1], action, 1.0]) @ B

# 4) 学 reward model，加入二次项以表达“离目标越远惩罚越大”
def reward_features(latent, action):
    u, v = latent
    return np.array([1.0, u, v, u*u, v*v, u*v, action*action])

R = np.stack([reward_features(zz, aa) for zz, aa in zip(z_next, actions)])
w_reward, *_ = np.linalg.lstsq(R, rewards, rcond=None)

def predict_reward(latent, action):
    return float(reward_features(latent, action) @ w_reward)

# 5) 从真实 observation 校正起点，此后只在 latent 里 imagination
start_true = np.array([-1.2, 0.0])
start_latent = encode(observe(start_true)[None, :])[0]
horizon, gamma = 6, 0.97

best_return, best_actions = -np.inf, None
for action_seq in itertools.product((-1.0, 0.0, 1.0), repeat=horizon):
    latent = start_latent.copy()
    imagined_return = 0.0
    for k, action in enumerate(action_seq):
        latent = latent_step(latent, action)
        imagined_return += gamma**k * predict_reward(latent, action)
    if imagined_return > best_return:
        best_return, best_actions = imagined_return, action_seq

# 6) 只为验证，把选出的动作放回真实环境执行
state = start_true.copy()
true_return = 0.0
for k, action in enumerate(best_actions):
    state, reward = true_step(state, action)
    true_return += gamma**k * reward

print("chosen actions:", best_actions)
print("final true state:", np.round(state, 3))
print("imagined return:", round(best_return, 3))
print("true return:", round(true_return, 3))

one_step_error = np.mean((z_next - dyn_features @ B) ** 2)
print("latent one-step MSE:", one_step_error)

assert one_step_error < 0.01
assert abs(state[0] - target) < abs(start_true[0] - target)
```

若把 `sensor` 换成强非线性图像、引入遮挡和随机接触，PCA 与线性 transition 很快失效，这正是 encoder、RSSM、stochastic latent 与 neural reward model 要解决的问题。

## ⚠️ 台阶 10：world model 最危险的失败不是“梦不够好看”，而是 actor 学会钻梦的漏洞

### 失败 1：Model exploitation

Actor 不会像普通测试集那样随机访问状态，它会主动搜索 predicted reward 高的区域。若 world model 在某个 OOD latent 区域错误地预测高 reward，actor 会反复利用这个错误。

### 失败 2：Compounding error

即使 one-step prediction 很准，多步 rollout 也会把小误差送回 transition，逐渐进入训练数据没覆盖的状态。

### 失败 3：Representation 丢掉控制关键细节

Decoder 重建得不错，不代表小目标、接触状态或安全信号被保留。需要专门测 task-relevant probes 与 closed-loop outcomes。

### 失败 4：Aleatoric 与 epistemic 混在一个 stochastic latent 里

随机 latent 能表达多未来，但单模型的 sampling spread 不自动等于校准后的 model uncertainty。对 OOD 风险，仍需要 ensemble、held-out calibration 或保守目标。

### 失败 5：Reward model 错了，世界“看起来对”也没用

高质量 observation reconstruction 不能弥补 reward / termination prediction 错误。相反，只预测 reward 而完全忽略环境结构，也可能在训练分布外崩溃。

因此评估要分层：

| 层级 | 关键问题 | 典型证据 |
|---|---|---|
| 表征 | latent 是否保留任务所需变量 | probe、reconstruction、reward prediction |
| 动力学 | action 后的 latent 是否正确 | one-step / multi-step error、action shuffle |
| 想象 | imagined return 是否和真实 return 对齐 | horizon-wise calibration、rank correlation |
| 行为 | actor 是否在真实环境有效 | return、success、sample efficiency |
| 安全 | actor 是否利用模型漏洞 | OOD rollout、uncertainty penalty、real-world violations |

## 🔗 和你的 CVPR / 偏振工作的连接

### 连接 1：latent 不应只保留“好看”的 RGB 信息

偏振任务的决策变量可能是 DoLP、AoLP 的周期方向、几何边界、相机位姿或材质状态。若 encoder 只为自然图像 reconstruction 优化，可能把这些低能量但物理关键的量压掉。应加入物理量预测、周期表示与 downstream probe。

### 连接 2：posterior / prior 对应“观测校正 / 无新观测预测”

真实偏振帧到来时，可以用 posterior 校正 latent；规划下一视角、analyzer angle 或光源动作时，只能让 prior rollout。若论文只展示 posterior reconstruction，不能证明模型能在无未来观测时稳定想象。

### 连接 3：active sensing 的 reward 可以是信息增益，但必须有真实闭环

可把 reward 定义为新观测使 depth / normal uncertainty 下降多少，让 actor 学选择下一次采集动作。但模型自己预测“不确定性下降”不等于真的下降，必须在 held-out 真实采集或受控模拟器中验证。

### 连接 4：不要把生成的 counterfactual 当 ground truth

Latent rollout 可用于提出候选动作、扩展训练信号或做敏感性分析，但模型生成的未来不能反过来证明同一模型学到了真实物理。生成证据、真实 intervention 与 downstream evidence 要分开。

## 🎤 面试角度

### Q1：Dreamer 为什么要同时有 posterior 与 prior？

Posterior 在训练/真实过滤时看当前 observation，用它校正 latent；prior 在未来 observation 不存在时，仅靠历史 state 与 action 预测下一 latent。KL 让 prior 接近 posterior，才能从真实起点稳定进入 imagination。

### Q2：RSSM 中 deterministic 与 stochastic state 各做什么？

Deterministic recurrent state 记住跨时间历史，stochastic state 表达同一历史约束下的多种可能状态。只有前者容易平均多未来，只有后者又难保存长时记忆。

### Q3：Dreamer 与 MPC 的区别是什么？

MPC 在每个决策时刻用模型在线搜索动作序列；Dreamer 主要在训练时用 imagined trajectories 优化 actor-critic，执行时直接由 actor 输出动作。两者都依赖 model accuracy，但计算分配不同。

### Q4：为什么需要 value model？

有限 imagination horizon 看不到很远的 reward。Value model 在 horizon 尾部 bootstrap 更远回报，$\lambda$-return 再混合不同长度的 targets，平衡 bias 与 variance。

### Q5：latent rollout 比 pixel rollout 好在哪里，又牺牲了什么？

它降低维度和反复生成成本，把容量集中到可控动力学与 reward；代价是 representation 可能丢掉重要细节，而且 latent error 不容易靠肉眼发现，所以更依赖任务、闭环与 OOD 诊断。

## 🧠 一句话总结

Dreamer 类 latent world model 用 posterior 从真实 observation 校正 RSSM state，用 KL 训练不看未来图像的 prior 逼近 posterior，再从真实 latent 起点沿 action 在 prior 中想象 reward、continuation 与 future state；critic 用 $\lambda$-return 接续有限 horizon，actor 则在 imagined dynamics 中学习高回报行为——它省去了反复像素渲染，却没有消除 model bias，因此最终证据必须来自真实环境的闭环表现，而不是“梦里得分”或漂亮 reconstruction。
