## ⏮ 上篇回顾（30 秒）

上篇建立了两条关键关系：

$$
\tilde{\mathbf x}_2^\top\mathbf F\tilde{\mathbf x}_1=0,
\qquad
\tilde{\mathbf x}_j\sim\mathbf P_j\tilde{\mathbf X}.
$$

第一式约束“两个像素是否可能来自同一个三维点”，第二式在相机矩阵已知时把匹配像素三角化为三维点。

但真实照片集一开始通常什么都没有：

```text
不知道哪些像素对应同一点；
不知道每台相机在哪里；
不知道场景中有哪些三维点。
```

SfM（Structure from Motion）要从这三个未知量互相纠缠的闭环里启动。

## 🎬 开篇：SfM 为什么像“先拼地图，再给每张照片定位”

想象你拿到几百张旅游照片，没有 GPS，也没有拍摄顺序。单张照片只给出射线；两张照片若有足够重叠，可以从共同特征估计相对姿态；一旦得到少量相机和三维点，新照片就能借已有地图定位，再为地图补点。

Incremental SfM 的主循环因此是：

```text
特征提取 → 图像匹配 → 几何验证
        → 选择初始图像对
        → 三角化初始点云
        → 用 2D–3D 对应注册新相机
        → 三角化新点
        → Bundle Adjustment
        → 重复直到没有可注册图像
```

COLMAP 是这套经典管线的工程化实现。理解它时，不要把它看成一个“重建按钮”，而要看成多个带质量门槛的估计问题串联起来。

## 🧩 台阶 1：局部特征把图像变成可匹配的观测

对第 $j$ 张图像，特征提取器给出关键点位置与描述子：

$$
\mathcal K_j=\{(\mathbf u_{jk},\mathbf d_{jk})\}_{k=1}^{N_j}.
$$

其中：

- $\mathbf u_{jk}=[u_{jk},v_{jk}]^\top$ 是第 $k$ 个关键点的像素坐标；
- $\mathbf d_{jk}\in\mathbb R^D$ 是 $D$ 维 descriptor；
- $N_j$ 是该图像检测到的关键点数量。

Detector 负责回答“哪些位置值得记”，descriptor 负责回答“这个局部区域长什么样”。经典 SIFT 用尺度空间寻找稳定关键点，并把局部梯度方向统计成对尺度和一定旋转变化较稳健的描述子。现代 learned features 改变了特征如何产生，却没有改变后续几何问题：外观相似只是候选证据，不是三维对应的证明。

若图像 $a$ 中描述子 $\mathbf d_i$ 与图像 $b$ 中最近、次近描述子的距离分别为 $r_1,r_2$，ratio test 检查

$$
\frac{r_1}{r_2}<\tau.
$$

当最近邻并没有明显优于次近邻时，匹配很可能来自重复纹理。再加 mutual check：$a\to b$ 和 $b\to a$ 都选择对方，能继续削掉一批歧义。

但窗户、栅栏、树叶仍会产生“描述子很像、几何上却不是同一点”的 outlier，所以还需要 RANSAC。

## 🎲 台阶 2：RANSAC 怎样从多数错误中找出一个几何模型

设共有 $M$ 组候选匹配，真实内点比例为 $w$。某个模型最少需要抽取 $s$ 组对应；例如 normalized 8-point algorithm 需要 $s=8$。

一次随机抽样全部来自内点的概率是

$$
p_{\text{good}}=w^s.
$$

一次失败概率为 $1-w^s$。独立抽样 $N$ 次全部失败的概率是

$$
p_{\text{fail}}=(1-w^s)^N.
$$

希望至少成功一次的置信度为 $p$，即

$$
1-(1-w^s)^N\ge p.
$$

移项、取对数：

$$
(1-w^s)^N\le 1-p,
$$

$$
N\log(1-w^s)\le\log(1-p).
$$

因为 $0<1-w^s<1$，所以 $\log(1-w^s)<0$；两边除以负数时不等号反向：

$$
\boxed{
N\ge\frac{\log(1-p)}{\log(1-w^s)}
}.
$$

这解释了为什么低内点率会让 RANSAC 代价爆炸：$w$ 被提升到 $s$ 次方。优质 descriptor、ratio test、匹配策略不是几何验证的替代品，却能显著减少几何验证要承受的组合搜索。

对候选 fundamental matrix $\mathbf F$，不能只看代数残差 $\tilde{\mathbf x}_2^\top\mathbf F\tilde{\mathbf x}_1$，因为它会随坐标尺度变化。常用 Sampson distance 近似点到对应极线的几何误差：

$$
d_{\text{S}}=
\frac{(\tilde{\mathbf x}_2^\top\mathbf F\tilde{\mathbf x}_1)^2}
{(\mathbf F\tilde{\mathbf x}_1)_1^2+(\mathbf F\tilde{\mathbf x}_1)_2^2+
(\mathbf F^\top\tilde{\mathbf x}_2)_1^2+(\mathbf F^\top\tilde{\mathbf x}_2)_2^2}.
$$

下标 $1,2$ 表示齐次直线向量的前两个分量。RANSAC 用阈值把 $d_{\text{S}}$ 足够小的匹配判作 inlier，再用全部内点重新估计模型。

## 🕸️ 台阶 3：不是每两张图都要匹配

$n$ 张图像若全连接匹配，要检查

$$
\frac{n(n-1)}{2}
$$

个图像对，复杂度随 $n^2$ 增长。实际系统会根据数据形态选匹配策略：

- **Exhaustive matching**：小型无序照片集，覆盖全面但成本高；
- **Sequential matching**：视频或按拍摄顺序排列的数据，优先匹配邻近帧；
- **Retrieval / vocabulary-tree matching**：先找视觉上可能重叠的图像，再做局部匹配；
- **Spatial matching**：有 GPS 等粗位置时，用空间近邻筛选候选。

几何验证后得到 view graph：节点是图像，边表示两张图有足够可靠的几何内点。好的 view graph 既要局部边可靠，也要有跨区域连接；否则重建会碎成多个 component，或沿长序列逐渐漂移。

## 🌱 台阶 4：初始化为什么不能随便挑两张图

Incremental SfM 先选一对图像估计 $\mathbf E$ 或 $\mathbf F$，分解相对位姿，再三角化初始点。

初始对需要同时满足：

1. 足够多且分布广的几何内点；
2. 足够视差，使三角测量夹角不至于太小；
3. 场景不是接近纯平面或纯旋转的退化情况；
4. 两边有足够多点满足 positive depth（cheirality）。

这里存在真实权衡：视角太近，外观容易匹配但三角化病态；视角太远，baseline 好却可能遭遇遮挡和强外观变化。初始化一旦很差，后续 PnP 和 bundle adjustment 只是在错误地基上优化。

从 essential matrix 分解时会得到多组 $\mathbf R,\mathbf t$ 候选。把匹配点逐组三角化，选择使最多点同时位于两台相机前方的解。平移仍只有方向，因此初始重建带一个任意尺度。

## 📍 台阶 5：新照片怎样通过 PnP 加入已有地图

假设地图已有三维点 $\mathbf X_i$，新图像中观察到对应像素 $\mathbf u_i$。Perspective-n-Point（PnP）估计新相机位姿 $\mathbf R,\mathbf t$：

$$
\min_{\mathbf R,\mathbf t}
\sum_{i\in\mathcal V}
\rho\!\left(
\left\|
\mathbf u_i-
\pi(\mathbf K,\mathbf R,\mathbf t,\mathbf X_i)
\right\|_2^2
\right).
$$

其中：

- $\mathcal V$ 是新图像与已有 3D track 的 2D–3D 对应集合；
- $\pi$ 表示三维点经过外参、内参和透视除法后的像素投影；
- $\rho$ 是 robust loss，用于降低残余 outlier 的影响。

PnP 也放在 RANSAC 中：随机抽最小 2D–3D 集合提出位姿，再统计重投影内点。注册成功后，新相机与尚未成为地图点的匹配 observation 可以形成新的三角化射线。

为什么优先注册“看见最多已有 3D 点”的图像？因为 2D–3D 覆盖越充分、空间分布越广，PnP 越稳定，也更容易把新区域可靠地接到旧地图上。

## 🧵 台阶 6：Track 才是跨多张图的同一个三维点

两张图之间的一对匹配只是 edge。若图像 $a$ 的点 $i$ 匹配图像 $b$ 的点 $j$，而 $b$ 的点 $j$ 又匹配图像 $c$ 的点 $k$，系统尝试把它们合并为一个 track：

$$
\mathcal T_m=\{(a,i),(b,j),(c,k),\ldots\}.
$$

同一 track 理论上对应同一个三维点 $\mathbf X_m$。它要满足多视图重投影一致性：

$$
\mathbf u_{jm}\approx
\pi(\mathbf K_j,\mathbf R_j,\mathbf t_j,\mathbf X_m).
$$

长 track 通常提供更强约束，但“出现次数多”并不自动可信：重复建筑构件可能把不同物理点错误合并。系统必须在三角化角度、重投影误差、track 冲突和观测连通性之间做过滤。

## 🔧 台阶 7：Bundle Adjustment 为什么是整条管线的核心

前面的估计是逐步的：两视图位姿有误差，三角化继承误差，PnP 又使用已有地图。若只一路向前，误差会累积。

Bundle Adjustment（BA）把所有相机参数与三维点重新放回同一个目标：

$$
\boxed{
\min_{\{\boldsymbol\theta_j\},\{\mathbf X_i\}}
\sum_{(i,j)\in\mathcal O}
\rho\!\left(
\left\|
\mathbf u_{ij}-
\pi(\boldsymbol\theta_j,\mathbf X_i)
\right\|_2^2
\right)
}
$$

$\boldsymbol\theta_j$ 包含第 $j$ 台相机的旋转、平移，必要时还包括焦距或畸变参数；$\mathcal O$ 是所有有效观测。

在当前参数附近做一阶线性化。把全部待优化增量写成 $\Delta\boldsymbol\xi$，残差堆叠成 $\mathbf r$，Jacobian 为 $\mathbf J$：

$$
\mathbf r(\boldsymbol\xi+\Delta\boldsymbol\xi)
\approx
\mathbf r(\boldsymbol\xi)+\mathbf J\Delta\boldsymbol\xi.
$$

忽略 robust weighting 时，最小化平方残差得到 normal equation：

$$
\mathbf J^\top\mathbf J\Delta\boldsymbol\xi
=-\mathbf J^\top\mathbf r.
$$

关键结构是：一个像素观测只连接“一台相机”和“一个三维点”，所以 $\mathbf J$ 很稀疏。利用 Schur complement 先消去大量点变量，能把主要线性求解缩到相机变量上，这正是大规模 BA 可行的原因之一。

### Gauge freedom：为什么必须固定坐标系

如果把所有相机和点同时做同一个 similarity transform——整体旋转、平移和缩放——重投影不会改变。因此纯视觉 SfM 的解不是唯一的。

工程上通常固定第一台相机姿态，并固定一个尺度自由度；若需要 metric reconstruction，还要引入已知 baseline、标尺、GPS/IMU 或其他真实尺度观测。否则 BA 的 Hessian 会沿 gauge direction 奇异或近奇异。

## 💻 最小可运行代码：RANSAC 次数为什么会突然爆炸

下面只依赖 Python 标准库。它计算在给定内点率、最小样本数和目标置信度下，RANSAC 至少需要多少轮，并用 Monte Carlo 检查公式。

```python
import math
import random


def required_trials(inlier_ratio, sample_size, confidence=0.99):
    one_good = inlier_ratio ** sample_size
    if one_good <= 0.0:
        return math.inf
    if one_good >= 1.0:
        return 1
    return math.ceil(
        math.log(1.0 - confidence) / math.log(1.0 - one_good)
    )


def monte_carlo_success(inlier_ratio, sample_size, trials, runs=20000):
    # One trial succeeds with probability w**s. Therefore one whole RANSAC
    # run succeeds with probability 1 - (1 - w**s)**trials. Sampling that
    # Bernoulli event directly avoids millions of unnecessary inner loops.
    one_good = inlier_ratio ** sample_size
    success_probability = 1.0 - (1.0 - one_good) ** trials
    return sum(
        random.random() < success_probability for _ in range(runs)
    ) / runs


random.seed(7)
for w in [0.8, 0.5, 0.3]:
    n = required_trials(w, sample_size=8, confidence=0.99)
    empirical = monte_carlo_success(w, 8, n)
    print(f"inlier_ratio={w:.1f}, trials={n:5}, empirical={empirical:.4f}")
```

你会看到：内点率从 $0.8$ 降到 $0.5$ 或 $0.3$，所需轮数不是线性增加，而是因为 $w^8$ 急剧变小而暴涨。这也是大规模 SfM 必须同时优化检索、描述子匹配和几何验证的原因。

## 🧯 台阶 8：COLMAP 重建失败时，应该看哪一层

### 症状 1：匹配很多，却注册不了相机

可能原因包括重复纹理造成的假匹配、匹配集中在局部、近纯旋转、平面退化、内参/畸变模型错误。应看 geometric inliers、空间覆盖和重投影分布，而不只看 raw match count。

### 症状 2：只重建出多个碎片

View graph 缺少跨区域桥接边。可以改善拍摄重叠、使用更合适的 retrieval/spatial matching，或检查曝光和视角变化是否让共同特征消失。

### 症状 3：点云像“拉面”一样弯曲或漂移

长序列缺乏 loop closure、相机模型不合适或 BA 约束不足。需要跨段匹配、可靠回环、更好的 calibration，必要时加入外部位姿/尺度信息。

### 症状 4：重投影误差低，几何仍然错

低重投影误差只表示当前相机—点配置能解释像素，不保证 metric scale 正确，也不保证错误 track 没有形成自洽局部结构。还要检查轨迹连通性、相机运动、点深度、三角化角和独立测量。

## 🔬 与你的 CVPR / 偏振任务连接

### 1. COLMAP pose 是输入证据，不是绝对真值

若后续 NeRF、3DGS 或多视图偏振把 COLMAP pose 当监督，SfM 的漏注册、尺度歧义和局部漂移会传给下游。论文应报告 registered images、track length、reprojection error、重建 component 和尺度对齐方式，而不是只写“poses from COLMAP”。

### 2. 偏振特征未必满足普通外观不变性

AoLP / DoLP 会随视角、表面法向、折射率以及 diffuse/specular 成分改变。同一点跨视角的偏振观测可以是物理信号，也会破坏把它当灰度纹理直接匹配的假设。更稳妥的做法是用 RGB 或几何稳健特征建立 correspondence，再把偏振用于法向/材质约束，并显式处理周期性。

### 3. “更多视图”只有在新增约束可靠时才有价值

低 overlap、动态物体或小三角化角的额外视图可能增加错误约束。可以借鉴 reliability 思路：按 track 几何、view angle、reprojection residual 和 polarization consistency 选择或加权观测，但权重必须在 held-out 数据上证明能降低真实几何误差。

### 4. 公平消融要区分前端与后端

更换 learned matcher 后结果变好，可能来自更多注册图像，也可能来自 BA 获得更多观测，而不一定说明最终表示更强。应分别报告：匹配内点率、注册率、track statistics、pose/geometry error 与下游任务指标。

## 🎤 面试角度：高频追问与答法

### Q1：SfM 中为什么已经有 RANSAC，还需要 robust BA？

**答：** RANSAC 在模型提出阶段去除大 outlier，但阈值内仍有噪声和残余错配；BA 联合优化所有相机与点，robust loss 可降低大残差观测对最终解的支配。两者工作在不同阶段，不能互相替代。

### Q2：为什么 incremental SfM 用 PnP 注册新图，而不是每次重新做两视图？

**答：** PnP 把新图像直接定位到已有全局坐标系，利用多组 2D–3D 对应；单独两视图只得到局部相对位姿与不定尺度，容易产生新的坐标片段和累计漂移。

### Q3：Bundle adjustment 与 pose graph optimization 有什么区别？

**答：** BA 直接最小化像素重投影误差，同时优化相机与三维点；pose graph 通常优化相机节点之间的相对位姿约束，不显式保留每个图像观测点。BA 更贴近原始测量，但变量更多、计算更重。

## 🧠 一张脑图：今天的因果链

```text
局部特征与候选匹配
  └─ RANSAC + F/E → 几何内点与 view graph
       └─ 可靠初始对 → 相对位姿 + 初始三角化
            └─ 2D–3D correspondences → PnP 注册新相机
                 └─ 新视图带来新 track / 新三维点
                      └─ BA 联合优化相机、点与必要内参
                           └─ 过滤坏观测，继续增量注册
```

## 一句话总结

SfM 不是直接从照片“生成点云”，而是一个交替建立对应、相机和结构的估计系统：局部特征产生候选，RANSAC 用极线几何筛出可信匹配，可靠初始对建立第一个坐标系，PnP 把新照片定位到已有地图，三角化扩充 3D tracks，bundle adjustment 再用所有像素观测联合修正相机与点。COLMAP 的强大来自这条闭环，也意味着任何前端错配、退化初始化或相机模型错误都会沿闭环传播。
