# 2026-11-28 · 等一局结束再复盘，还是每走一步就学习：Monte Carlo、TD、Q-learning 与 Exploration

> 阶段 O · 第 2 篇 ｜ 标签：reinforcement learning, Monte Carlo, temporal-difference learning, bootstrapping, TD error, SARSA, Q-learning, on-policy, off-policy, epsilon-greedy, exploration

## ⏮ 上篇回顾（30 秒）

O1 把长期决策写成 MDP：state $S_t$、action $A_t$、reward $R_{t+1}$ 与 next state $S_{t+1}$ 由 transition 连接，return

$$
G_t=R_{t+1}+\gamma R_{t+2}+\gamma^2R_{t+3}+\cdots
$$

汇总当前 action 对整条未来的影响；Bellman equation 又把它压缩成“一步 reward + next value”。

但 O1 的 Value Iteration 默认我们能够对 transition distribution 求和。真实机器人通常只拿到一条条 sample：做了动作、看到下一状态、收到一个 reward。今天要回答的是：**没有完整环境模型时，怎样仅靠经历学出 value？**

## 🎯 主菜 · 三种“用未来教现在”的办法

先固定一个 policy $\pi$，只做 prediction：估计在该 policy 下各 state 的 $V^\pi(s)$。随后再进入 control：一边估计 $Q(s,a)$，一边改进 policy。

### 第一层：所有 sample-based 方法都在逼近同一个期望

State value 的定义是：

$$
V^\pi(s)=\mathbb E_\pi[G_t\mid S_t=s].
$$

符号逐个解释：

- $\pi(a\mid s)$：处于 $s$ 时选择 action $a$ 的概率；
- $G_t$：从时刻 $t$ 开始的随机 return；
- $\mathbb E_\pi$：对 policy 选择与环境随机性共同取期望；
- 条件 $S_t=s$：只统计从 state $s$ 出发的经历。

如果我们能重复访问 $s$，每次都会看到不同的 $G_t$。最直接的方法就是用这些 sample return 的平均值逼近它的期望。这就是 Monte Carlo 的入口。

### 第二层：Monte Carlo——先走到终点，再把真实回报倒着分给沿途 state

一条 episode 为：

$$
S_0,A_0,R_1,S_1,A_1,R_2,\ldots,S_T,
$$

其中 $S_T$ 是 terminal state。对 episode 中时刻 $t$，可以从真实观察到的 reward 计算：

$$
G_t=R_{t+1}+\gamma R_{t+2}+\cdots+\gamma^{T-t-1}R_T.
$$

用 incremental mean 更新：

$$
V(S_t)\leftarrow V(S_t)+\alpha\left[G_t-V(S_t)\right].
$$

这里：

- $\alpha\in(0,1]$ 是 step size；
- $G_t$ 是本轮完整 return sample；
- $G_t-V(S_t)$ 是新证据与旧估计之差。

若用第 $n$ 次访问时的 $\alpha_n=1/n$，这个递推就是 sample average。因为 target $G_t$ 完全由实际 reward 构成，没有用当前 $V$ 猜自己的 target，所以 Monte Carlo **不 bootstrapping**。

它的优点是 target 直接来自完整结果；代价也很明确：

1. 必须等 episode 结束才知道 $G_t$；
2. 很长甚至 continuing task 难以等待终点；
3. $G_t$ 混入从 $t$ 到 $T$ 的所有随机性，variance 往往较大；
4. 一个早期 state 要等很久才能获得 credit。

“不 bootstrapping”不等于“无偏且永远更好”。若 episode 被人为截断、behavior 改变或 return 被 clipping，target 仍可能偏；即便无偏，高 variance 也会让学习很慢。

### 第三层：Temporal-Difference——只等一步，用下一状态的旧估计补齐未来

Bellman expectation equation 告诉我们：

$$
V^\pi(s)
=\mathbb E_\pi\left[R_{t+1}+\gamma V^\pi(S_{t+1})\mid S_t=s\right].
$$

如果真实 $V^\pi$ 未知，我们先用当前估计 $V$ 代替它。TD(0) 的 one-step target 是：

$$
Y_t^{\mathrm{TD}}=R_{t+1}+\gamma V(S_{t+1}).
$$

更新为：

$$
V(S_t)\leftarrow V(S_t)+\alpha\delta_t,
$$

其中 TD error 为：

$$
\delta_t
=R_{t+1}+\gamma V(S_{t+1})-V(S_t).
$$

这一步只需等到 next state 出现，所以能够 online learning。它把已经观察到的 $R_{t+1}$ 与尚未走完的未来估计 $V(S_{t+1})$ 拼起来。

为什么叫 **bootstrapping**？因为当前估计 $V(S_t)$ 的 target 中包含另一个当前估计 $V(S_{t+1})$：模型在用自己尚未完全学准的结果继续训练自己。

这会带来一组 trade-off：

- 比完整 return 更早更新，通常 variance 更低；
- target 依赖当前 $V$，训练早期带有 bias；
- next-state error 会沿 Bellman backup 传播；
- 若 representation、sampling 与 off-policy correction 不匹配，错误也可能被反复放大。

### 第四层：TD error 为什么不只是“预测差”，而是局部 Bellman inconsistency

固定 $S_t=s$，对 TD error 取条件期望：

$$
\begin{aligned}
\mathbb E_\pi[\delta_t\mid S_t=s]
&=\mathbb E_\pi[R_{t+1}+\gamma V(S_{t+1})-V(s)\mid S_t=s]\\
&=\mathbb E_\pi[R_{t+1}+\gamma V(S_{t+1})\mid S_t=s]-V(s).
\end{aligned}
$$

当 $V=V^\pi$ 时，Bellman equation 给出：

$$
\mathbb E_\pi[\delta_t\mid S_t=s]=0.
$$

所以单次 $\delta_t=0$ 不是必要条件——transition 与 reward 可以随机；真正的 fixed-point 条件是**同一 state 上的期望 TD error 为零**。

这也解释了为什么一条 transition 的大 $|\delta_t|$ 不自动表示“异常”或“重要”：它可能来自正常 stochasticity、reward noise、state aliasing，也可能来自 value 尚未收敛。Priority replay 可以使用 TD error 排序 sample，但不能把它直接当成已校准 uncertainty。

### 第五层：从 prediction 到 control——要估计的是 $Q(s,a)$

Control 不只问“这个 state 好不好”，还要比较 action：

$$
Q^\pi(s,a)=\mathbb E_\pi[G_t\mid S_t=s,A_t=a].
$$

学到 $Q$ 后，可以构造 greedy policy：

$$
\pi_{\mathrm{greedy}}(s)=\arg\max_a Q(s,a).
$$

但若从一开始永远 greedy，初始估计偶然偏高的 action 会被反复选择，其他 action 没有数据，错误就无法纠正。这就是 exploration 的入口。

### 第六层：SARSA 与 Q-learning 的差别，只差一个 target，却是在回答两个 policy

#### SARSA：学习当前 behavior policy 的 value

观察五元组

$$
(S_t,A_t,R_{t+1},S_{t+1},A_{t+1}),
$$

用实际将要执行的 next action $A_{t+1}$ 更新：

$$
Q(S_t,A_t)\leftarrow Q(S_t,A_t)
+\alpha\left[
R_{t+1}+\gamma Q(S_{t+1},A_{t+1})-Q(S_t,A_t)
\right].
$$

若 $A_{t+1}$ 来自 $\epsilon$-greedy policy，SARSA 的 target 就把“以后仍会偶尔探索”纳入价值。它是典型 **on-policy TD control**。

#### Q-learning：用 behavior 收数据，target 却朝 greedy policy 更新

Q-learning 把 next action 换成最大值：

$$
Q(S_t,A_t)\leftarrow Q(S_t,A_t)
+\alpha\left[
R_{t+1}+\gamma\max_{a'}Q(S_{t+1},a')-Q(S_t,A_t)
\right].
$$

当前 transition 可以由探索性 behavior policy 产生，但 target 假设以后选择 greedy action。因此它是 **off-policy TD control**：

~~~text
behavior policy：决定数据从哪里来
target policy：决定正在估计谁的 value
~~~

“off-policy”不表示 behavior 无关紧要。若某些 state-action 从未被访问，Q-learning 根本没有证据更新它们。经典 tabular 收敛结论需要反复覆盖 state-action、合适的 step-size schedule、stationary Markov environment 等条件；deep RL 中这些条件通常不会原样成立。

### 第七层：$\epsilon$-greedy 提供随机尝试，但不保证有用覆盖

对有限 action set $\mathcal A(s)$，$\epsilon$-greedy 为：

$$
A_t=
\begin{cases}
\arg\max_a Q(S_t,a), & \text{概率 }1-\epsilon,\\
\text{从 }\mathcal A(S_t)\text{ 随机采样}, & \text{概率 }\epsilon.
\end{cases}
$$

若随机分支均匀采样，非 greedy action 也有至少 $\epsilon/|\mathcal A(s)|$ 的单步机会。但这不等于整个 state space 被覆盖，因为：

- 很多 state 只有经过一串特定 action 才能到达；
- sparse reward 让随机动作几乎看不到成功；
- dangerous action 不能靠“撞几次试试”探索；
- continuous action space 中均匀随机通常没有任务意义；
- 环境、机器人或人类响应会随时间改变。

Exploration 的核心不是“多加噪声”，而是**在信息收益、任务收益、成本与安全之间选择数据收集行为**。Count bonus、optimism、entropy、intrinsic motivation、uncertainty-directed exploration 与 active perception 都是在改变这个选择规则，但每一种都需要真实 coverage 与 safety evidence。

### 第八层：Monte Carlo、TD、SARSA、Q-learning 放在一张表里

| 方法 | Target | 等到何时更新 | Bootstrapping | Policy 关系 | 主要风险 |
|---|---|---|---|---|---|
| Monte Carlo prediction | 完整 $G_t$ | episode 结束 | 否 | 通常 on-policy | 高 variance、长 credit delay |
| TD(0) prediction | $R+\gamma V(S')$ | 一步后 | 是 | 通常 on-policy | target bias、error propagation |
| SARSA | $R+\gamma Q(S',A')$ | next action 已选 | 是 | on-policy | exploratory policy 的表现进入 target |
| Q-learning | $R+\gamma\max_{a'}Q(S',a')$ | 一步后 | 是 | off-policy | max overestimation、coverage / extrapolation |

不要把表中的“优缺点”理解成固定排名。方法表现取决于 episode 结构、reward noise、representation、data distribution、step size、target update 与任务安全约束。

## 💻 最小可运行代码：同一条 Random Walk 上比较 Monte Carlo 与 TD(0)

环境有 5 个非终止 state，编号 1–5。每步以相同概率向左或向右：

- 到达左端 state 0：episode 结束，reward 0；
- 到达右端 state 6：episode 结束，reward 1；
- 其他 transition：reward 0；
- $\gamma=1$。

对随机 policy，state $s$ 先到右端的概率是 $s/6$，所以真实 value 为：

$$
V^\pi(s)=\frac{s}{6},\qquad s=1,\ldots,5.
$$

~~~python
import random

random.seed(7)

N_STATES = 5
EPISODES = 20_000


def step(state):
    next_state = state + random.choice((-1, 1))
    reward = 1.0 if next_state == N_STATES + 1 else 0.0
    return next_state, reward


def monte_carlo(alpha=0.005):
    value = [0.0] * (N_STATES + 2)
    for _ in range(EPISODES):
        state = 3
        visited = []
        while state not in (0, N_STATES + 1):
            visited.append(state)
            state, reward = step(state)

        # 本环境只有终点 reward；整条 episode 的 return 就是最后 reward。
        final_return = reward
        for state in visited:
            value[state] += alpha * (final_return - value[state])
    return value[1:-1]


def td_zero(alpha=0.01):
    value = [0.0] * (N_STATES + 2)
    for _ in range(EPISODES):
        state = 3
        while state not in (0, N_STATES + 1):
            next_state, reward = step(state)
            target = reward + value[next_state]
            value[state] += alpha * (target - value[state])
            state = next_state
    return value[1:-1]


truth = [state / 6 for state in range(1, 6)]
print("truth:", [round(x, 3) for x in truth])
print("MC:   ", [round(x, 3) for x in monte_carlo()])
print("TD(0):", [round(x, 3) for x in td_zero()])
~~~

固定 seed 的一次输出：

~~~text
truth: [0.167, 0.333, 0.5, 0.667, 0.833]
MC:    [0.153, 0.307, 0.488, 0.638, 0.824]
TD(0): [0.167, 0.322, 0.486, 0.676, 0.867]
~~~

这不是在证明 TD 永远比 MC 准。这里使用 constant step size，最终估计会在真值附近持续波动；两段训练还消耗了不同的随机 trajectory。公平比较应冻结环境、episode budget、random seed protocol，跨多个 seed 报告 learning curve、sample efficiency 与 final error，而不是挑一次输出定输赢。

## ⚠️ 工程边界：为什么 Bellman target 也会把错误“自洽”起来

### 1. Behavior coverage 决定能学什么

Dataset 没覆盖的 state-action 没有 counterfactual outcome。Function approximator 可能仍给它高 Q，但这是 extrapolation，不是经验支持。

### 2. `max` 会选择估计噪声中的高值

若多个 action 的 Q 都含噪声，$\max$ 更容易选中被高估者。Double Q-learning 的核心就是把 action selection 与 value evaluation 部分解耦，减轻 maximization bias。

### 3. Bootstrapping、function approximation 与 off-policy 会相互放大

三者组合常被称为 deadly triad。它不是说所有 deep Q-learning 必然发散，而是提醒我们：移动 target、共享参数与分布外 backup 会破坏 tabular 直觉，需要 target network、replay design、conservative objective、监控与真实 rollout 验证。

### 4. Exploration reward 不等于真实任务收益

Intrinsic reward 可以帮助访问新区域，也可能诱导 agent 追逐“容易制造的新奇”。评估时要分开 extrinsic task return、coverage、information gain、constraint violation 与真实 harm。

### 5. Safety 不能只靠期望 return

两个 policy 平均 return 相同，一个可能稳定完成，另一个可能多数时候成功但偶尔造成严重事故。需要报告 distribution、worst group、tail risk、intervention、recovery、constraint violation 与 executed harm。

## 🔗 与我 CVPR / 偏振三维工作的连接

假设机器人可以选择 viewpoint、analyzer angle 或 illumination，用新观测改进三维重建，再执行抓取。可以把：

- state / belief：当前 geometry、pose、material 与 uncertainty；
- action：移动相机、旋转偏振片、改变照明或停止采集；
- reward：真实 geometry / task gain 减去时间、能耗与风险；
- transition sample：执行采集 action 后得到的新 observation 与重建结果。

若用 Q-learning 学采集策略，至少要冻结并记录：

1. behavior policy 实际访问了哪些 scene / view / analyzer action；
2. reward 用的是 training loss、predicted uncertainty，还是独立 surface / task endpoint；
3. polarization action 的收益是否来自正确 calibration，而不是曝光或 capacity 差异；
4. predicted Q、realized one-step gain、episode return 与 safety cost 是否分别报告；
5. held-out scene 上是否仍覆盖困难材质、遮挡和 grazing angle；
6. random、uniform、greedy uncertainty、oracle 等 matched acquisition baseline 是否共享预算。

一个 policy 在 simulator 里获得高 return，只能证明它优化了该 simulator、reward 与 data distribution。要声称“偏振促进真实主动三维重建”，还需要真实采集、独立 geometry endpoint、matched sensor budget 与 failure subgroup。

## 🔧 配菜 · 面试考点

**Q1：Monte Carlo 与 TD 的根本区别是什么？**

**A：**MC 用完整 observed return 作为 target，不 bootstrapping，通常要等 episode 结束；TD 用一步 reward 加当前 next-state value 作为 target，能够 online 更新，但引入 target bias 与 error propagation。

**Q2：TD error 的期望何时为零？**

**A：**当估计 $V$ 满足给定 policy 的 Bellman equation 时，对同一 state 的条件期望 TD error 为零。单次 transition 的 TD error 不必为零。

**Q3：SARSA 与 Q-learning 为什么分别称为 on-policy / off-policy？**

**A：**SARSA 的 target 使用 behavior 实际选择的 $A'$；Q-learning 使用 $\max_{a'}Q(S',a')$，即用探索 behavior 收数据，却学习 greedy target policy 的 value。

**Q4：$\epsilon$-greedy 是否保证探索充分？**

**A：**不保证。它只在已访问 state 中给 action 随机机会，不能保证深层 state 可达、sparse reward 可发现、continuous action 有效或危险 action 可安全尝试。

**Q5：为什么 offline Q-learning 容易高估 OOD action？**

**A：**Dataset 缺少这些 action 的 outcome，function approximator 仍会外推；`max` 又偏好高估项，bootstrapping 把该估计继续写入前序 target。

**Q6：MC target 来自真实回报，是否就一定比 TD 可靠？**

**A：**不是。MC 的完整 return 可能 variance 很高、反馈很晚，并受 truncation 与 behavior distribution 影响；TD 的 bias–variance trade-off 在很多任务中更有利。应按 frozen protocol 比较 learning curve 和最终 decision outcome。

## 一句话总结

Monte Carlo 等 episode 结束，用完整 return 教当前 state；TD 只等一步，用 reward 加 next value 组成 bootstrapped target；SARSA 把当前探索 policy 的 next action 写进 target，Q-learning 则用探索 behavior 收数据、用 greedy `max` 学 target policy。它们都不是凭公式从无到有创造知识：state-action coverage、target bias、function approximation、reward contract 与 safety evidence 共同决定学到的 value 能否用于真实决策。
