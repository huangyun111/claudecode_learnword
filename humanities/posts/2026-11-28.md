# 2026-11-28 · 病例曲线往上走，是传播变快了，还是我们看得更清楚了：传染病与流行病学

> 模块 H15 · 第 2 篇 ｜ 标签：infectious disease, epidemiology, incidence, prevalence, attack rate, surveillance, R0, Rt, generation interval, epidemic curve, outbreak investigation, intervention

## ⏮ 上篇回顾（30 秒）

H15-1 区分了 symptom、sign、test result、diagnosis 与 screening：检查结果会更新疾病概率，却不会自动变成诊断或治疗决定；同一项检查的 PPV 还随 pre-test probability 改变。

今天把视角从一个人移到一群人。公共卫生面对的不是“这位患者是否患病”一个问题，而是：**新感染是否正在增加、传播发生在哪里、病例曲线为何变化、哪种干预真正切断了传播？**

## 🎬 开篇：周一 100 例，周五 200 例，疫情一定翻倍了吗

病例报告增加可能来自至少五条不同路径：

~~~text
真实感染增加
检测可及性提高
就医意愿改变
病例定义扩大
报告积压在某天集中释放
~~~

相反，报告下降也可能是周末少采样、轻症不就医、实验室延迟或 surveillance 中断。

因此，一条曲线从来不是病原体本身。它是：

~~~text
感染过程
→ 症状与就医
→ 采样与检测
→ 病例定义
→ 上报与修订
→ 最终被我们看见的数字
~~~

流行病学首先要把“世界发生了什么”与“观测系统看见了什么”分开，再把二者重新连接。

## 📖 主线：传播、观测与干预是三份不同的账

### 第一层：Incidence 看新发生，Prevalence 看当前存量

**Incidence（发病 / 发生）**关心某段时间里新出现的事件。若在风险人群中观察一年，可以写 cumulative incidence：

$$
\text{Cumulative incidence}
=\frac{\text{期间新发病例数}}
{\text{期初有风险人数}}.
$$

若每个人被观察的时间不同，更适合用 incidence rate：

$$
\text{Incidence rate}
=\frac{\text{新发病例数}}
{\text{总 person-time at risk}}.
$$

**Prevalence（患病率 / 现患比例）**关心某一时点或期间有多少人正处于该状态：

$$
\text{Point prevalence}
=\frac{\text{某时点现有病例数}}
{\text{该时点总人口数}}.
$$

可以把 prevalence 想成水池存量：

~~~text
新发 incidence 流入
→ 当前病例 prevalence
→ 康复、死亡或离开人群流出
~~~

所以高 prevalence 可能因为 incidence 高，也可能因为病程长、康复慢；低 prevalence 可能因为传播少，也可能因为病程极短或死亡快。对急性传染病，今天的现患病例还强烈依赖 recovery / isolation 的速度。

在一场边界明确、持续较短的 outbreak 中，常用 **attack rate**：

$$
\text{Attack rate}
=\frac{\text{outbreak 期间新病例}}
{\text{outbreak 开始时有风险人群}}.
$$

它本质上是该场景下的 cumulative incidence，不是病原体脱离时间、人群和暴露条件后的永久属性。

### 第二层：病例数是感染过程经过 Detection Funnel 后的结果

设时刻 $t$ 的真实新感染数为 $I_t$，被 surveillance 报告的新病例数为 $C_t$。一个最简观测关系是：

$$
C_t\approx p_t I_{t-d},
$$

其中：

- $p_t$：感染最终被发现并报告的概率；
- $d$：从感染到检测 / 报告的 delay；
- $I_{t-d}$：更早发生、到今天才进入数据的感染。

$p_t$ 并非常数。它会随症状严重度、检测政策、资源、就医行为、病例定义、实验室能力和报告系统改变。真实模型还要把 incubation、onset-to-test 与 reporting-delay distribution 展开，而不是只用一个固定 $d$。

这解释了为什么“今日新增”不能被直接读成“今日感染”：

1. 感染发生在前；
2. 症状、检测与报告发生在后；
3. 不同个体的 delay 不同；
4. 最近几天的数据还可能继续补录。

Surveillance 的任务不是无误差地拍下全部感染，而是用稳定定义和多源信号尽早发现变化，并持续估计自己的盲区。

### 第三层：$R_0$ 与 $R_t$ 不是“病毒战斗力排行榜”

**Basic reproduction number $R_0$** 表示：在一个近似完全 susceptible、没有相关免疫和特定控制条件的人群中，典型感染者平均造成多少 secondary infection。

它不是只由病原体决定。接触网络、居住密度、行为、环境、传染期与测量假设都会进入，因此同一种病原体在不同情境下的估计可能不同。

**Effective reproduction number $R_t$** 则描述时刻 $t$ 的现实条件下，每位感染者平均产生多少 secondary infection。它会同时反映：

- susceptible fraction；
- 既往感染 / vaccination 等免疫；
- contact pattern 与 seasonality；
- isolation、mask、ventilation、treatment 等 intervention；
- 病原体本身变化；
- surveillance data 与 estimation model 的假设。

在稳定且可比较的条件下：

- $R_t>1$：每代感染平均扩张；
- $R_t<1$：每代感染平均收缩；
- $R_t=1$：每代规模大致持平。

但这不是“今天病例一定涨 / 跌”的机械开关。Observed cases 有 delay，$R_t$ 是模型估计且带 uncertainty；imported cases、cluster heterogeneity 与 reporting artifact 也会使短期曲线偏离简单解释。

### 第四层：Generation Interval 决定“一代传播”要多久

**Generation interval** 是一个感染者被感染，到其传染另一个人之间的时间。它通常不是固定数字，而是一种 distribution，记作 $w_s$：传播间隔为 $s$ 天的概率权重。

一个简化 renewal equation 是：

$$
I_t
=R_t\sum_{s=1}^{\infty} I_{t-s}w_s.
$$

逐项理解：

1. 过去每一天 $t-s$ 的感染者都可能在今天造成新感染；
2. $w_s$ 描述相隔 $s$ 天发生传播的相对可能性；
3. 加权和给出今天的 infection pressure；
4. $R_t$ 把这份压力缩放成今天的新感染。

因此，相同的 $R_t$ 不一定对应相同增长速度。若 generation interval 更短，同样的“每代翻倍”会在日历时间里更快发生。反过来，用错误的 generation-interval assumption 估计 $R_t$，也会改变结果。

这就是为什么不能只比较两个 $R$ 数字，却忽略估计窗口、数据源、delay correction 与 generation-interval distribution。

### 第五层：传播可以拆成 Contact、Transmission Probability 与 Infectious Duration

在一个非常简化、均匀混合的框架里，可以把 reproduction potential 想成：

$$
R\approx
\underbrace{c}_{\text{单位时间有效接触}}
\times
\underbrace{p}_{\text{每次接触传播概率}}
\times
\underbrace{D}_{\text{可传播持续时间}}.
$$

这不是精确通用公式，但能帮助定位 intervention：

- 减少高风险接触、避免拥挤：主要作用于 $c$；
- ventilation、mask、hand hygiene 等：按传播路径作用于 $p$；
- 早发现、有效 isolation / treatment：可能缩短有效 $D$；
- vaccination / prior immunity：减少 susceptible 或降低感染、传播、重症的相应概率；
- vector control、water sanitation：直接改变特定传播链。

现实人群并不 homogeneous。少数高连接场所、household、workplace、school、hospital 或 mass gathering 可以形成 cluster。平均 $R_t$ 相同，传播集中程度与 intervention priority 仍可能完全不同。

所以公共卫生不是只问“把平均接触降多少”，还要问传播在哪里发生、谁承担成本、谁无法远程工作、谁难以获得检测与休假支持。有效政策需要生物机制，也需要可执行条件。

### 第六层：Surveillance 不是一种数据，而是一组互补传感器

常见 surveillance source 包括：

- **Case reporting**：有临床 / 实验室定义，适合追踪已识别病例，但受 testing 与 reporting 影响；
- **Syndromic surveillance**：用发热、咳嗽、急诊主诉等较早信号提高 timeliness，specificity 较低；
- **Laboratory surveillance**：确认病原体与 variant / subtype，但 sample 不一定代表总体；
- **Hospitalization / death**：更接近严重结局，却 lag 更长且受年龄、免疫、治疗与 admission practice 影响；
- **Sentinel surveillance**：固定机构系统采样，利于稳定比较，却不是 census；
- **Wastewater / environmental surveillance**：可在个体就医之外看到 community signal，但从浓度到感染人数需要处理稀释、排放、采样与模型 uncertainty；
- **Serosurveillance**：帮助估计既往暴露 / immune marker，却受 antibody kinetics、assay 与 vaccination 影响。

多源数据的价值不是简单投票，而是利用不同 observation process 互相校验。若 case、test positivity、hospitalization 与 wastewater 同向变化，解释更稳；若分歧，就要先问各自的 denominator、delay 和 measurement change。

### 第七层：Epidemic Curve 是线索，不是自动因果结论

按 symptom onset 或 specimen date 绘制 epidemic curve，可以帮助观察：

- 是否集中在一个时间窗；
- 是否出现多个传播波；
- 是否有周期性或 reporting artifact；
- intervention 前后趋势何时改变；
- 哪些病例可能共享 exposure period。

经典直觉中：

- 单次 point-source exposure 可能形成较集中峰；
- 持续 common source 可能形成较长平台；
- person-to-person propagated outbreak 可能出现相隔一个 generation interval 左右的连续波峰。

但真实曲线会被 small sample、multiple introductions、behavior change、case definition 与 delay 模糊。曲线形状只能生成 hypothesis，不能单独确认传播方式或 source。

### 第八层：Outbreak Investigation 为什么边调查、边控制、边修正

一场 outbreak investigation 常包含这些相互迭代的步骤：

1. 判断 observed cases 是否超过该 time / place / population 的 expected level；
2. 核实 diagnosis 与 laboratory / clinical evidence；
3. 建立明确、可执行的 case definition；
4. 主动 case finding，建立 line list；
5. 按 time、place、person 做 descriptive epidemiology；
6. 形成关于 source、route 与 risk factor 的 hypothesis；
7. 用 cohort、case-control、environmental sampling 等检验；
8. 实施 control measures；
9. 继续 surveillance，检查措施是否有效和是否有副作用；
10. 公开沟通方法、uncertainty、更新与最终结论。

顺序并非必须机械串行。若后果严重、传播机制合理且 intervention 风险低，不必等所有论文式证据完成才控制；但紧急行动也不应终止数据收集。较好的逻辑是：

~~~text
采取可逆、机制匹配的保护措施
→ 明确记录依据与不确定性
→ 持续观察结果
→ 根据新证据扩大、调整或停止
~~~

### 第九层：怎样判断“干预后下降”是不是干预造成的

“措施开始后病例下降”可能是真效果，也可能混入：

- 疫情本来已经接近峰值；
- susceptible / high-contact network 已发生变化；
- 同期还有其他措施；
- testing 与 case definition 改变；
- 人们在正式政策前已经自发改变行为；
- reporting delay 让下降看起来提前或延后。

所以评价 intervention 要尽量说明：

1. estimand 是 infection、symptomatic disease、hospitalization 还是 death；
2. 比较组 / counterfactual 来自哪里；
3. intervention timing 与 outcome delay 怎样对齐；
4. 是否有 interrupted time series、matched region、cluster randomization 或自然实验；
5. uptake、adherence 与 co-intervention 是否记录；
6. average effect 是否掩盖 age、occupation、region 与 access subgroup；
7. benefit、harm、cost 与 equity 是否一起报告。

机制、时间顺序和统计关联要共同成立，才更接近 causal claim。

## 🌍 与当下的连接

### Dashboard 为什么应显示 specimen / onset date，而不只显示 report date

Report date 容易制造周末低谷与集中补报。Onset date 更接近疾病过程，specimen date 更接近检测过程，但二者也会缺失或回填。成熟 dashboard 应标注 date definition、recent-data incompleteness 与 revision。

### Wastewater 上升为什么是早期信号，却不是精确病例换算器

它绕过了部分就医和个体 testing bias，但仍受排放量、降雨、管网、采样频率、laboratory method 与服务人口估计影响。适合看趋势和交叉验证，不宜假装每个浓度点都能无误差换算为感染人数。

### “本地没有病例”为什么可能只表示 surveillance 没看见

若轻症多、检测难、报告弱或 stigma 高，零报告与零感染并不等价。需要结合 sampling effort、test volume、sentinel source 与 environmental signal 判断 detection limit。

### 为什么传播控制不仅是个人意志问题

Isolation 是否可行取决于 paid sick leave、居住条件、照护责任、工作制度和医疗可及性。只给个人建议却不给行动条件，会让同一生物学措施产生高度不平等的执行率和负担。

## 一张可复用的疫情数字十五问卡

1. 数的是 infection、case、symptom、test、hospitalization 还是 death？
2. 分子是什么，denominator 是 population、tests、person-time 还是 susceptible contacts？
3. 用的是 onset、specimen、admission 还是 report date？
4. Case definition 是否改变？
5. Testing availability、care-seeking 与 reporting delay 是否改变？
6. 最近数据是否尚未补齐？
7. 报告的是 incidence、prevalence 还是 attack rate？
8. $R_0/R_t$ 的人群、时间窗和 generation-interval assumption 是什么？
9. Imported case 与 local transmission 是否区分？
10. 是否存在 cluster、superspreading 或 contact heterogeneity？
11. 多个 surveillance source 是否同向？
12. Intervention 作用于 contact、transmission probability、duration 还是 susceptibility？
13. Outcome delay 是否与 intervention timing 对齐？
14. Average trend 是否掩盖 subgroup 与 access inequality？
15. 何种新证据会让当前判断或措施改变？

## 💬 谈资点 / 反常识洞见

1. **病例增加不一定只表示传播增加，也可能表示 detection funnel 变宽；但“检测变多”也不能在没有 denominator 的情况下自动解释一切。**
2. **Prevalence 是存量，不只由 incidence 决定，还取决于病程与流出速度。**
3. **$R_0$ 不是病原体的固定战斗力；它属于病原体、人群接触、环境与假设共同构成的系统。**
4. **相同 $R_t$ 配上不同 generation interval，会产生不同的日历增长速度。**
5. **Surveillance 的目标不是幻想看见全部感染，而是知道自己通过什么过程看见了谁、漏掉了谁。**
6. **Outbreak control 与 investigation 不必二选一：可以先采取可逆保护，同时用持续 surveillance 检查效果并修正。**
7. **平均传播下降不等于负担公平；无法居家、请假或获得检测的人可能承担更高风险和政策成本。**

## 一句话总结

Incidence 记录新发生，prevalence 记录当前存量；$R_0$ 描述特定初始 susceptible 条件下的传播潜力，$R_t$ 描述现实时间点的有效传播，而 generation interval 把“每代传播”换算到日历速度。病例曲线则是感染经过症状、就医、检测、定义和报告后的观测结果。成熟的流行病学不会把一个数字当成病原体真相，而是同时审计传播机制、surveillance process、时间延迟、population denominator、intervention counterfactual 与不平等负担。
