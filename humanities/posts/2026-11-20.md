# 2026-11-20 · 眼睛看见了，大脑就记住了吗：知觉、注意与记忆为何不是录像

> 模块 H14 · 心理、认知与社会行为 ｜ 标签：sensation, perception, attention, inattentional blindness, working memory, episodic memory, reconstructive memory, misinformation effect, source monitoring, eyewitness
> 主线：人不是先完整记录世界、再偶尔忘掉细节。外界刺激先被感官转成信号，知觉再结合情境组织意义，有限注意决定哪些信息得到深入处理，记忆则在 encoding、storage 与 retrieval 中不断受线索和已有知识影响。承认这些限制，不等于“一切都是主观的”，而是要求把可靠判断建立在更好的观察条件、记录、独立证据和防污染程序上。

## 开篇：同一场十秒钟的事故，为什么三个人会讲出三个版本

路口发生轻微碰撞。站在路边的甲一直看着手机，只在巨响后抬头；乙注意到一辆车闯灯，却没看清驾驶员；丙看到了驾驶员，但后来反复听别人说“那辆车冲得很快”。

半小时后，三个人都真诚地讲述“自己看见的事故”，却在速度、先后顺序和人物细节上不一致。

这不一定意味着其中有人撒谎。一次回忆至少穿过四道门：

~~~text
外界刺激
→ 感觉系统接收了什么
→ 知觉怎样组织和解释
→ 注意选择了什么进入深度加工
→ 记忆怎样编码、保存并在当前线索下重建
~~~

日常语言常把这四步压成一句：“我亲眼看见，所以我记得很清楚。”心理学首先要拆开的，正是这个过度压缩。

## 第一层：Sensation 不是 Perception

**Sensation（感觉）** 是感受器对光、声、压力、温度等刺激作出反应，并把物理能量转成神经信号。

**Perception（知觉）** 则是大脑组织、区分和解释这些信号，使我们经验到“那是一辆向左转的车”“那个人在生气”。

两者不能混为一谈。视网膜收到的是不同波长与强度的光，不会直接收到“危险”“朋友”或“红灯违规”这样的意义。意义来自感觉证据与情境、先验、任务目标共同作用。

可以用一个朴素的 Bayesian 结构理解：

$$
p(H\mid E)
=\frac{p(E\mid H)p(H)}{p(E)},
$$

其中：

- $H$ 是对外界原因的假设，例如“阴影里是一个人”；
- $E$ 是当前 sensory evidence；
- $p(H)$ 是已有经验给出的 prior；
- $p(E\mid H)$ 是若假设成立，出现当前证据的可能性；
- $p(H\mid E)$ 是结合证据后的判断。

这不是说大脑每次都显式计算公式，而是提示：知觉既受 bottom-up evidence 约束，也会被 top-down expectation 影响。

在雾里，模糊轮廓可能被先验补成行人；在熟悉办公室里，一件位置异常的物品反而容易被忽略。先验让知觉更快，却也会在证据不足时带来系统性误判。

## 第二层：Detection 不是一个固定开关

我们常想象刺激“超过阈值就一定看见，低于阈值就一定看不见”。现实更像 signal detection：判断同时受 signal、noise 与 decision criterion 影响。

设内部 evidence variable 为 $x$。观察者选择一个 criterion $c$：

- 若 $x\ge c$，报告“有信号”；
- 若 $x<c$，报告“无信号”。

于是会有四种结果：

| 真实情况 | 报告有 | 报告无 |
|---|---:|---:|
| 有信号 | hit | miss |
| 无信号 | false alarm | correct rejection |

当漏掉危险物的代价极高时，人会降低 criterion，增加 hit，也同时增加 false alarm；当误报代价很高时，criterion 会升高，miss 可能增加。

所以“他没报告看见”不能直接等于“刺激不存在”，也不能直接等于“他的眼睛坏了”。还要问 illumination、distance、duration、noise、expectation、task 与 decision cost。

## 第三层：Attention 不是聚光灯照亮一切，而是有限资源分配

一个热闹路口同时提供颜色、运动、声音、面孔、文字和空间位置。若全部做同等深度加工，系统会被信息量淹没。Attention 的作用之一，就是选择哪些信号获得更强处理。

经典的 inattentional blindness 研究让参与者专注统计传球次数。即使一个显眼的意外人物穿过画面，许多人仍没有报告看到。关键不是眼睛没有接收到光，而是任务把有限 attention 分给了别处。

这说明三件事：

1. **看向某处不等于处理了那里的一切。** 眼球方向与 conscious awareness 不是同一个变量。
2. **没有注意到，不等于刺激不显眼。** 显眼性还要相对当前 task 来判断。
3. **我们对自己“应该看见多少”的直觉常常过于乐观。** 丰富的主观画面感，不等于保存了同样丰富的细节。

Change blindness 也有相似结构：若场景变化被眨眼、镜头切换或短暂遮挡打断，大变化也可能未被发现。视觉系统更擅长维护当前任务需要的结构，而不是逐像素保存整个世界。

## 第四层：Working Memory 像工作台，不像无限仓库

注意选中的信息，还需要在短时间内被保持和操作。Working memory 可以理解为当前思考的工作台：

- phonological loop 暂时保持语音 / 言语材料；
- visuospatial sketchpad 暂时保持视觉与空间信息；
- central executive 协调任务、更新和抑制；
- episodic buffer 把不同来源的信息与长期记忆接起来。

这个系统容量有限。边开车边写复杂消息的问题，不只是“手被占用”，还包括两个任务争夺视觉、空间、语言和 executive control。

同样，学习时把一页公式看完，不等于已经进入长期记忆。若 working memory 被太多未分组符号占满，后续关系就难以建立。Chunking、结构化解释和把新知识连到旧知识，作用不是让短时容量无限扩大，而是让有限工作台处理更有意义的单元。

## 第五层：Memory 是过程，不是一个文件夹

一次 episodic memory 至少涉及：

1. **Encoding**：事件发生时，哪些信息被加工并形成 memory trace；
2. **Storage / consolidation**：痕迹在时间中怎样保持和变化；
3. **Retrieval**：后来在某种 cue 下怎样访问过去信息。

任何一步都可能失败。

- 当时没注意，是 encoding failure；
- 时间、干扰或状态变化会削弱可用痕迹；
- 没有合适 cue 时，信息可能暂时提取不出；
- retrieval 时，新信息和当前信念可能进入重建。

因此“想不起来”不总等于“从未存过”，“非常生动”也不自动等于“细节准确”。Vividness、confidence、accuracy 是相关但不同的变量。

## 第六层：为什么说回忆是 Reconstructive，而不是 Reproductive

Reproductive memory 像播放原始录像：储存什么，之后原样读出什么。

Reconstructive memory 更像依据残留证据、语义知识、情境与 retrieval cue 重建一个最连贯版本。重建并非缺陷的同义词；它让人能压缩经验、抽取意义、把旧知识用于新情境。但同一个机制也会产生 distortion。

Loftus 与 Palmer 的经典实验让参与者观看车辆碰撞影片。之后问题中仅替换描述碰撞的动词，就会影响速度估计；后续还会影响对原画面不存在细节的报告。语言没有简单“删除一段录像”，而是进入了后来重建事件的材料。

这类影响可用 source monitoring 问题理解：

> 我记得这个细节，但它来自当时亲眼所见、后来听别人说、自己推断，还是反复想象？

内容熟悉度上升时，来源标签未必同步变强。于是“好像早就知道”可能只是后来信息被反复提取。

## 第七层：Misinformation Effect 不等于“人可以被随意洗脑”

承认 memory 可被误导，不应夸大成“任何记忆都能轻易植入”。影响大小取决于：

- 原始 encoding 质量；
- 事件到误导信息之间的时间；
- 提问方式与来源可信度；
- 新旧信息是否一致；
- 是否提醒参与者区分来源；
- retrieval 是否被多次反馈污染；
- 研究测量的是细节、选择还是完整虚假事件。

不同 false-memory paradigm 也未必共享同一个机制。更稳妥的结论是：memory report 是证据，但它的可靠性依赖获取条件与程序，不能只凭“讲得很确定”打包判断。

## 第八层：Confidence 到底有没有用，要看它何时、怎样被记录

“自信与准确完全无关”过于绝对；“越自信越准确”也过于简单。

关键是 measurement condition。第一次、未受污染、公平程序下立即记录的 confidence，与经过重复询问、确认反馈、共同讨论之后在庭审中表达的 confidence，不是同一个变量。

反馈会改变一个人的解释：

~~~text
最初有些犹豫
→ 他人说“你选对了”
→ 反复讲述同一版本
→ 熟悉感和叙事连贯性上升
→ 后来更确信“我当时看得很清楚”
~~~

因此严谨程序会尽早记录原始描述与 confidence，避免主持人知道“正确答案”而无意提示，并把后来的变化保留下来。

## 第九层：这不是“客观世界不存在”，而是客观判断需要制度化纠错

知觉与记忆受限，并不推出所有版本同样正确。相反，它告诉我们为什么要增加相互独立的 evidence channel：

- 尽快写下原始观察，区分 observation 与 inference；
- 保存照片、视频、时间戳和 sensor metadata；
- 独立询问多名观察者，避免先互相统一口径；
- 用非诱导问题，允许回答“不知道”或“不确定”；
- 记录第一版陈述与后续修改，不只保留最后版本；
- 把 testimony 与 physical evidence、记录和其他来源交叉核验。

心理学的价值不是让人对一切怀疑，而是把“相信自己”升级为“建立可检查的证据过程”。

## 与当下的连接：短视频、生成式 AI 与“我明明见过”

今天的信息环境把 perception 与 memory 的旧限制放大了。

### 1. Attention 由平台竞争

标题、推送、剪辑与 autoplay 争夺有限 attention。被频繁展示的内容更容易进入 processing，但 exposure 不等于 truth。

### 2. Context 更容易被切掉

十秒片段可能是真实画面，却省略前因后果。视觉 evidence 本身未必伪造，interpretation 仍可能被 caption 与剪辑改变。

### 3. Repetition 增加 Familiarity

一个说法反复出现后，人可能更容易提取它，却忘了最初来源是未经核实的转述。

### 4. Synthetic media 增加 Source Monitoring 负担

生成图片、克隆声音与真实片段混合传播后，仅凭“画面很真”不足以判断 provenance。需要来源、时间、原文件、交叉报道与取证链。

这也解释了为什么 media literacy 不能只教“识别假图”：即使图是真的，attention、framing、caption 与 memory contamination 仍可能改变结论。

## 对学习的连接：为什么重读很顺，不等于真正记住

反复重读会增加 perceptual fluency：文字越来越熟，理解感越来越顺。但熟悉感不一定能在没有原文时支持 retrieval。

更可靠的学习策略来自同一套机制：

- **主动回忆**：合上材料，尝试从 cue 提取；
- **间隔复习**：让 retrieval 在不同时间再次发生；
- **解释连接**：把新概念接到已有结构，改善 encoding；
- **交错练习**：练习区分相似问题，而不是只在同一模板中重复；
- **错误校正**：先作答再看反馈，并明确错误来自知识缺失还是 cue 误判。

学习不是把页面曝光次数最大化，而是让未来需要使用知识的条件，与练习 retrieval 的条件更接近。

## 五种常见误解

### “我盯着那里，所以肯定看见了”

Gaze direction 不能保证 attention 已处理目标，更不能保证细节被编码。

### “两个人说得不一样，至少一人在撒谎”

他们可能处在不同位置、注意不同目标、接受不同后续信息。差异需要调查，不能直接推成欺骗。

### “记忆会重建，所以证词都没有价值”

错误。证词的价值取决于 viewing condition、首次记录、提问程序、污染风险和独立 corroboration。

### “自信永远不代表准确”

也过度。初次、未污染、公平测试下的 confidence 可能有信息；被反馈和重复叙述改造后的 confidence 不能与其等同。

### “多看几遍就一定能学会”

重复 exposure 常提升 familiarity，却未必提升在新 cue 下独立 retrieval 与迁移。

## 一张可复用的“知觉—记忆十八问卡”

1. **Stimulus**：外界实际提供了什么信号？
2. **Condition**：距离、时长、光照、噪声怎样？
3. **Sensation**：感官是否有机会接收到？
4. **Task**：当时的人在做什么？
5. **Attention**：资源被分配给了哪里？
6. **Expectation**：什么 prior 影响了解释？
7. **Criterion**：漏报与误报哪个代价更高？
8. **Encoding**：哪些细节真正进入加工？
9. **Interference**：之后出现了哪些相似或冲突信息？
10. **Delay**：多久以后才第一次询问？
11. **Cue**：问题怎样措辞，是否暗示答案？
12. **Source**：细节来自看见、听说、推断还是想象？
13. **Repetition**：是否多次讲述同一版本？
14. **Feedback**：有没有人确认、否定或奖励某个答案？
15. **Confidence**：何时、在什么程序下记录？
16. **Revision**：第一版与后续版本怎样变化？
17. **Corroboration**：有哪些独立物证或记录？
18. **Boundary**：结论能支持“可能”“很可能”还是“确定”？

## 谈资点 / 反常识洞见

1. **我们不是先完整看见世界，再决定记住哪部分；注意在“看见什么”这一层已经参与选择。**
2. **主观画面很丰富，不代表大脑保存了同样丰富的逐像素记录。**
3. **回忆更像用痕迹和线索重建，而不是从硬盘读取原视频。**
4. **重复讲述可能提高 fluency 与 confidence，却不保证增加原始 evidence。**
5. **“不知道”不是证词失败，而是防止 forced choice 制造假确定性的必要选项。**
6. **承认人会错，不会摧毁客观性；它解释了为什么客观性需要记录、独立证据与纠错程序。**

## 可靠来源

- [OpenStax Psychology 2e, Sensation versus Perception](https://openstax.org/books/psychology-2e/pages/5-1-sensation-versus-perception)：区分 sensation 与 perception，并介绍 threshold、attention 与 context 对知觉的影响。
- [Simons & Chabris, Gorillas in Our Midst — Perception 1999](https://www.chabris.com/Simons1999.pdf)：用动态任务展示 sustained inattentional blindness，说明 focused attention 与主观视觉丰富度之间的落差。
- [Baddeley, Working Memory: Looking Back and Looking Forward — Nature Reviews Neuroscience 2003](https://doi.org/10.1038/nrn1201)：回顾 limited-capacity working memory 及 phonological、visuospatial 与 executive components。
- [McDermott & Roediger, Memory: Encoding, Storage, Retrieval — Noba](https://nobaproject.com/textbooks/jack-arnal-introduction-to-psychology-the-full-noba-collection/modules/memory-encoding-storage-retrieval)：说明 episodic / semantic / working memory、encoding 与 retrieval cue，并强调 remembering 的 reconstructive nature。
- [Loftus & Palmer, Reconstruction of Automobile Destruction — 1974](https://doi.org/10.1016/S0022-5371(74)80011-3)：展示 post-event question wording 如何影响速度估计与后续细节报告。
- [National Academies, Identifying the Culprit: Assessing Eyewitness Identification](https://www.nationalacademies.org/read/18891/chapter/3)：把 eyewitness identification 放入 perception、encoding、storage、retrieval 与 noise 的科学框架。
- [APA, Policy and Procedure Recommendations for Eyewitness Identification Evidence](https://www.apa.org/pubs/journals/releases/lhb-lhb0000359.pdf)：给出尽早记录描述、避免 suggestive questioning、保留 viewing condition 与 confidence 等程序建议。

## 一句话总结

人类认识世界不是“相机拍摄—硬盘保存—原样播放”：sensation 把刺激转成信号，perception 用证据与 prior 组织意义，attention 决定有限资源投向哪里，working memory 维持当前加工，而 episodic memory 在 encoding、storage 与 retrieval 中借助线索重建过去；这套系统高效却会产生 inattentional blindness、source confusion 与 misinformation effect。可靠判断因此不能只依赖生动和自信，而要改善观察条件、尽早保存原始陈述、避免诱导与反馈污染，并用独立 evidence 校验。

## 今日打卡

- **今天理清了**：sensation、perception、attention、working memory 与 episodic retrieval 是不同环节。
- **听到“我亲眼看见”时多问一句**：当时的 viewing condition、task、attention 与第一次记录是什么？
- **听到“他说得非常自信”时多问一句**：这是第一次未污染的 confidence，还是反复反馈后的 confidence？
- **学习时多问一句**：我只是觉得熟，还是能在没有原文的新 cue 下主动提取？
- **复习提醒**：把 H13 的媒介 / 平台 gatekeeping 接到今天——平台先分配 attention，之后的 caption、repetition 与 social feedback 还会继续影响 memory。
- **下一篇**：H14-2 启发式、偏差与不确定判断——人在信息不足时怎样快速决策，又为什么会在 base rate、概率与损失面前系统性犯错。
